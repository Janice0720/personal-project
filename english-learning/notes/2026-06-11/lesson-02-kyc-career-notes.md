# 課後筆記 — Lesson 02：職場英文口說練習

**日期**：2026-06-11
**主題**：職場日常對話 ── KYC 稽核、壓力應對、職涯探索、數據分析答題

---

## 今日學習目標

- 練習用英文描述職場情境（稽核週）
- 學習如何在面試中具體回答「為什麼雇用你」
- 練習從中文想法直接轉換成英文句子

---

## 課堂重點摘要

1. 描述職場情境時，要用**具體細節**，不能用抽象詞彙
2. 面試回答公式：**問題是什麼 → 你做了什麼 → 結果如何**（以開戶流失案例為例）
3. 職涯探索：先排除不要的，再縮小範圍（排除戶外工作 → 排除高風險職業 → 鎖定 technical & skills jobs）
4. 老師核心觀念：**No one is fully prepared. Just do it.**

## 老師的關鍵糾正


| 你說的                                | 老師建議改成                                           | 重點                                    |
| ---------------------------------- | ------------------------------------------------ | ------------------------------------- |
| "I enjoy the nervous"              | "I enjoy this kind of nervousness / pressure"    | nervous 是形容詞，名詞應用 nervousness         |
| "no money laundry"                 | "no money laundering"                            | launder（動詞）→ laundering               |
| "deal with digital"                | "What are you doing digitally? / work with data" | 要具體說明做什麼                              |
| "I think a lot before I do things" | 老師：你不能永遠等到準備好才行動                                 | No one is fully prepared — just start |

## 文法重點

- **deal with** vs **handle**：兩者都可表示「應對」，`deal with` 更口語，`handle` 較正式
- **具體 vs 抽象**：老師一再強調，說話要具體（specific），不能說 "I like data"，要說 "In my company, we found the account opening rate dropped, so I used DB to analyze each step of the user journey..."
