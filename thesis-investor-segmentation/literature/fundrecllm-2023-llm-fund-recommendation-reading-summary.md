## 1. 論文基本資訊與摘要

| 項目 | 內容 |
|------|------|
| 英文標題 | FundRecLLM: Fund Recommendation Based on Financial News and Research Analyst Report |
| 作者 | Guang Yang、Peiyang He、Xuefeng Liu |
| 機構 | Amazon |
| 年份 | 2023 年 11 月 |
| 關鍵字 | large language model、generative AI、financial advisory、information extraction、text summarization |

### 原文摘要（重點）

金融諮詢須消化多來源資訊，過程冗長、降低時效。本文提出**多步驟框架 FundRecLLM**，以**大型語言模型（LLM）**同時消化並結合**財經新聞**與**產業別基金研究分析師報告**，協助基金推薦。以新聞／報告發布後的**週、月市場表現**為基準，計算推薦評分排序與基金績效排序間的 **NDCG（正規化折損累積增益）**。結果顯示：相較於「僅用新聞、無自我一致性」，加入**分析師報告**與**自我一致性（self-consistency）**可將 NDCG 由 **0.72 提升至 0.93**。

---

## 2. 研究背景與動機

- LLM 在金融領域既有應用多集中於**資訊萃取、摘要、情緒分析**（如 ChatGPT 對新聞標題評分、FinBERT 對分析師報告／財報電話會議評分）。
- 既有缺口：LLM 對**廣泛財經市場（如旅遊、農業等產業）的理解與推理**尚未被充分研究；且多僅做情緒分類，未進一步給出**具體、有理由佐證的基金推薦**。
- 金融諮詢需整合多來源資料、多步驟推理，故引入 **CoT（思維鏈）、ToolLLM、ReAct、Chaining LLM** 等多步驟推理／工具使用框架。

---

## 3. 研究貢獻

1. **鏈式工具**：以 LLM 依新聞與分析師報告的解讀，自動產生產業別基金推薦答案。
2. **消化原始分析師報告的通用方法**：處理常以 PDF 形式（逾 10 頁）發布的分析師報告。
3. **量化評估方法**：以基金市場表現（NDCG）評估推薦成效。

---

## 4. 方法架構總覽

```
財經新聞  → 新聞解讀器（News Interpreter，CoT 提示）→ 萃取實體（產業/情緒/理由）→ docstore
分析師報告(PDF) → 報告分析器（Report Analyzer）
        → 版面解析(Layout Parser)+OCR(Tesseract) → Map&Reduce 摘要 → 萃取實體 → docstore
                                    ↓
               仲裁器（Moderator，序列鏈）：以「產業」連結兩方實體
               → 情緒轉分數、加總、跨新聞/報告平均 → 產出基金推薦 + 市場洞察摘要
```

- 以**產業（industry）**為實體連結鍵，將新聞與報告對同一產業的情緒分數分別加總後**平均**，摘要則串接。

## 5. 核心元件與技術細節

| 元件 | 技術重點 |
|------|----------|
| 新聞解讀器 | 以 **CoT 提示**引導 LLM 回答子問題（影響哪個產業／情緒正負中立／理由），輸出 JSON 便於解析 |
| 報告分析器 | 以 **Layout Parser（mask-rcnn-X-101，PubLayNet 訓練）**解析 PDF 表格/文字/圖；**Tesseract OCR**（支援簡體中文）取字；報告逾 10 頁超出 LLM 脈絡窗，故採 **Map & Reduce** 逐頁摘要再彙整 |
| 序列鏈與 docstore | 以 LangChain Sequential Chain 實作；docstore 存各產業彙總摘要，透過**嵌入空間相似度檢索**取回相關產業洞察 |
| 自我一致性 | 針對同一提示以 temperature=0.8 生成 **5 個樣本**，透過**多數決（majority voting）**邊際化，降低 LLM 輸出隨機性 |

## 6. 實驗設計與資料

| 項目 | 內容 |
|------|------|
| 資料 | 自中國公開網站（如東方財富 eastmoney）爬取並人工篩選：**251 則非個股財經新聞** + **141 份產業研究分析師報告** |
| 篩選原則 | 過濾個股資訊，聚焦**產業別基金** |
| 發布日 | 2023-07-17 |
| 產業分類 | 依**申萬（SW）三級標準**，每個一級產業平均取 5 檔主題基金 |
| 基金價格 | 以 xalpha 取 2023-07-17 後每日價格，計算各一級產業週／月平均績效 |
| 選用 LLM | **ChatGLM**（針對中文問答與對話最佳化） |

## 7. 評估方法：情緒轉分數與 NDCG

**情緒 → 推薦分數對照**（報告偏買方，故權重不同）：

| 資訊來源 | 情緒 | 分數 |
|----------|------|------|
| 新聞 | 正/中立/負 | +1 / 0 / −1 |
| 報告 | 正/中立/負 | **+2 / +1** / −1 |

- 以 **Sentence Transformer** 將 LLM 輸出的產業概念對應回 SW 標準，並將二、三級產業映射至一級產業。
- 計算各一級產業之後續週／月基金績效並排序，再以 **NDCG** 比較「推薦評分排序」與「實際績效排序」。

---

## 8. 實驗結果

**不同設定下的 NDCG 分數：**

| 資訊來源 | 自我一致性 | NDCG@週 | NDCG@月 |
|----------|-----------|---------|---------|
| 僅新聞 | 否 | 0.73 | 0.72 |
| 僅新聞 | 是 | 0.77 | 0.82 |
| 僅報告 | 否 | 0.89 | 0.90 |
| 僅報告 | 是 | 0.89 | 0.90 |
| 新聞＋報告 | 否 | 0.78 | 0.79 |
| **新聞＋報告** | **是** | **0.91** | **0.93** |

- **自我一致性對新聞有效**（多數決使解讀收斂），對報告效果有限（報告較長、Map&Reduce 後解讀較發散，僅公共部門、金融、房地產等強訊號主導排序）。
- **報告排序 NDCG 高於新聞**：以房地產為例，新聞情緒偏負但分析師報告偏正（看重優質資產長期價值、央行降準等利多），而 2023-07-17 後房地產確實反彈，解釋報告排序較準。
- **最佳組合**：新聞＋報告＋自我一致性 → NDCG 0.93。

## 9. 結論與限制

### 9.1 結論
- 將基金推薦建模為**推薦與問答（Q&A）問題**，以 LLM 序列鏈分別解讀新聞與分析師報告，再由仲裁器整合。
- 主要挑戰為**多模態資料整合**與**克服 LLM 脈絡窗限制**（以雙平行管線＋Map&Reduce 解決）。

### 9.2 限制與未來方向
- **NDCG 為含噪評估**：同時反映情緒分類準確度與市場對情緒的反應；受時間限制僅追蹤單一日期發布之短期績效，需更多回測與評估方法。
- **未做消融**：使用報告全部頁面，但關鍵內容多在前 1–2 頁，宜研究指定頁面範圍之效果。
- **僅用 ChatGLM**：未與其他指令型／金融專用 LLM 比較。
