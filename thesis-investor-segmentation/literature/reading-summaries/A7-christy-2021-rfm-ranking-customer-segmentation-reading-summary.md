## 2. 研究背景與動機

- 企業面對龐大的顧客資料庫，如何有效識別高價值顧客、針對不同群體制定差異化行銷策略，成為 CRM 的核心挑戰。
- 傳統 RFM 模型（Recency、Frequency、Monetary）雖廣泛應用，但各指標的**相對重要性**在不同情境下有所不同，若三個構面等權加總，可能無法精確反映顧客的真實價值。
- 現有研究對 RFM 的各種**排名方式（ranking）**缺乏系統性比較，尤其是不同排名策略對後續分群結果的影響。
- 分群演算法的選擇（硬分群 vs. 模糊分群）對顧客分群結果有實質影響，值得並列比較。

---

## 3. 研究目的與問題

### 3.1 研究目的

提出一套以 **RFM 排名（RFM Ranking）** 為核心的顧客分群方法，透過對 RFM 三個構面進行排名並整合，再以 K-means 與 Fuzzy C-Means 進行分群，評估哪種組合在顧客分群上更為有效。

### 3.2 核心研究問題

1. 不同 RFM 排名方式（如等分法、百分位、組合加總）對分群結果有何影響？
2. K-means 與 Fuzzy C-Means 分別應用於 RFM 資料時，分群品質有何差異？
3. 哪種方法組合在顧客分群上表現最佳？

---

## 4. RFM 模型說明

### 4.1 三個構面定義

| 構面 | 英文全稱 | 定義 | 商業意義 |
|------|----------|------|----------|
| R（Recency） | 最近一次消費 | 距今最後一次購買的天數 | R 越小，顧客越活躍、互動越近期 |
| F（Frequency） | 購買頻率 | 研究期間內的購買次數 | F 越高，顧客忠誠度與黏著度越強 |
| M（Monetary） | 購買金額 | 研究期間內的累計消費金額 | M 越高，顧客貢獻度越大 |

### 4.2 RFM Ranking（核心貢獻）

- 本研究的核心創新在於提出並比較多種 **RFM 排名方式**，包括：
  - **等分法（Quintile Ranking）**：將 R、F、M 各自排序後均分為 N 等分，賦予 1～N 分
  - **百分位排名（Percentile Ranking）**：依各指標分布計算百分位數
  - **加總組合（Composite Score）**：三構面分數加總或加權後排名
- 不同排名方式產生不同的顧客分數分佈，進而影響分群結果。

### 4.3 RFM 指標的方向性

| 構面 | 分數方向 | 說明 |
|------|----------|------|
| R | **越小越好** | 最近購買天數少 → 顧客越活躍 → 分數應較高 |
| F | **越大越好** | 購買次數多 → 忠誠度高 → 分數應較高 |
| M | **越大越好** | 消費金額高 → 貢獻度大 → 分數應較高 |

> 注意：R 構面在賦分時方向相反（R 值越小 → R 分數越高），需在前處理中反轉。

## 5. 研究方法

### 5.1 整體流程

```
顧客交易資料
   → 計算 R、F、M 三構面原始值
   → RFM Ranking（等分法 / 百分位 / 加總等方式）
   → 標準化 / 正規化
   → 分群演算法（K-means 或 Fuzzy C-Means）
   → 分群評估（Silhouette Score、戴維森堡丁指數等）
   → 顧客分群輪廓詮釋
```

### 5.2 標準化處理

- RFM 三構面原始值的量綱不同（天數 vs. 次數 vs. 金額），需進行標準化（Z-score 或 Min-Max Normalization）後再輸入分群演算法，避免量綱差異主導距離計算。

## 6. 分群演算法比較：K-means vs. Fuzzy C-Means

### 6.1 K-means（硬分群）

| 項目 | 說明 |
|------|------|
| 分群邏輯 | 每個樣本被唯一指派至最近的群心（硬性分群） |
| 距離計算 | 歐氏距離（Euclidean Distance） |
| 優點 | 計算效率高、易於解釋 |
| 缺點 | 對離群值敏感；假設球形群簇；需事先指定 K 值 |
| 收斂 | 最小化組內平方和（Within-Cluster Sum of Squares, WCSS） |

### 6.2 Fuzzy C-Means（模糊分群）

| 項目 | 說明 |
|------|------|
| 分群邏輯 | 每個樣本對所有群體有**隸屬度（membership degree）**，介於 0 至 1 之間 |
| 特點 | 允許樣本同時「部分屬於」多個群體，適合邊界模糊的情況 |
| 優點 | 對行為介於多個群體之間的顧客更具彈性 |
| 缺點 | 解釋與後續應用較 K-means 複雜；計算成本較高 |

### 6.3 比較結論（原文實驗結果）

- 兩種演算法皆能有效識別 RFM 資料中的顧客群體。
- 在分群品質指標（Silhouette Score）上，兩者表現接近，但在特定資料集上 K-means 略優或相當。
- 硬分群（K-means）在實務應用與解釋上更為直觀，適合多數商業情境。

## 8. 實驗結果

- RFM Ranking（排名法）相較於直接使用原始 RFM 值，能產生**更均衡的分群分佈**，避免少數極端值主導群心。
- K-means 與 Fuzzy C-Means 均能識別出行為特徵各異的顧客群體（如高價值型、流失風險型、潛力成長型等）。
- 不同排名方式（等分法 vs. 百分位）對分群結果有輕微影響，但整體趨勢一致。
- **等分法（Quintile）是最常用且效果穩健**的 RFM 排名方式，在實務中應用最廣。

---

## 9. 研究結論

1. **RFM Ranking 是有效的顧客分群前處理方法**：相較於直接使用原始值，排名後的 RFM 分數具備更好的分佈特性，有助於提升 K-means 與 FCM 的分群品質。
2. K-means 適合多數顧客分群場景，FCM 則在顧客行為邊界模糊時提供更細緻的刻畫。
3. RFM 三構面的排名方式選擇會影響最終分群結果，應依資料分佈特性決定。
4. 分群後的各群顧客需以商業意義命名，才能有效轉化為行銷策略。

---

## 10. 研究限制

- 實驗以一般電商或零售資料為主，不直接涵蓋金融商品投資人情境。
- RFM 三構面的相對權重設定（若採加權方式）會影響分群，但本研究以排名法繞過此問題。
- 靜態 RFM 無法捕捉顧客行為隨時間的動態演變（如季節效應、交易頻率變化趨勢）。
- K 值的選定仍依賴手肘法等啟發式方法，不同 K 值可能導致不同詮釋。
