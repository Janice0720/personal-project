# E5 論文問答：白話解析
**論文**：陳一慈（2021）利用 RFM 模型與購物籃分析進行電子商務顧客分群與銷售策略之研究

---

## Q：購物籃分析的支持度、信賴度、提升度是什麼？怎麼計算？

---

### 先建立直覺：購物籃分析在做什麼？

購物籃分析的目標很單純：

> **找出「哪些商品常常被一起買」，並量化這種關聯有多強。**

經典的「啤酒與尿布」就是這個概念——超市分析大量購物紀錄後，發現這兩樣東西常出現在同一張購物清單裡，於是把它們擺在一起，銷售量果然提升。

這三個指標就是用來**量化這種「一起買」關係**的工具。

---

### 用一個共同的範例貫穿三個指標

假設超市有 **1,000 筆**購物紀錄（每筆 = 一位顧客的一次購物清單），其中：

- 買了「洗髮精」的清單有 **200 筆**
- 買了「護髮素」的清單有 **150 筆**
- 同時買「洗髮精＋護髮素」的清單有 **100 筆**

---

## 一、支持度（Support）

### 它在問什麼？

> 這個商品組合，在所有購物紀錄裡出現的比例有多高？

這個數字衡量「這個組合有多常見」，太罕見的組合就算關聯再強也沒有商業價值。

### 計算公式

```
Support(A, B) = 同時包含 A 和 B 的清單數 / 總清單數
```

### 帶入範例

```
Support(洗髮精, 護髮素) = 100 / 1,000 = 0.1（即 10%）
```

意思是：**每 100 張購物清單中，有 10 張同時出現洗髮精和護髮素。**

### 實務使用方式

- 分析師會設定一個**支持度門檻**（例如 0.003 = 0.3%），低於門檻的組合直接排除，不再計算後面的指標。
- E5 論文中設門檻 0.001（0.1%），找到了 1,049 組有意義的商品組合。

---

## 二、信賴度（Confidence）

### 它在問什麼？

> 「已知顧客買了 A」，他**同時也買 B** 的機率是多少？

這個數字衡量「A → B」這條規則有多可靠。

### 計算公式

```
Confidence(A → B) = Support(A, B) / Support(A)
```

也就是：同時買 A 和 B 的比例 ÷ 只要有買 A 的比例。

### 帶入範例

```
Support(洗髮精) = 200 / 1,000 = 0.2（20%）
Support(洗髮精, 護髮素) = 100 / 1,000 = 0.1（10%）

Confidence(洗髮精 → 護髮素) = 0.1 / 0.2 = 0.5（50%）
```

意思是：**在買了洗髮精的人裡，有 50% 也買了護髮素。**

### 直覺解讀

- 信賴度 50% → 規則「還算可靠」，一半的機率成立
- 信賴度 90% → 規則「非常可靠」，幾乎每個買 A 的人都買 B
- 信賴度 10% → 規則「很弱」，不太值得作為推薦依據

### 注意：方向很重要

信賴度是有方向性的：

```
Confidence(洗髮精 → 護髮素) ≠ Confidence(護髮素 → 洗髮精)
```

「買洗髮精 → 買護髮素」和「買護髮素 → 買洗髮精」是兩條不同的規則，信賴度可能不同，要分開計算。

---

## 三、提升度（Lift）

### 它在問什麼？

> A 和 B 的關聯，是真的有意義，還是只是「剛好兩者都很熱賣」造成的？

這是三個指標裡最重要的一個，因為它負責排除假警報。

### 為什麼需要提升度？

假設護髮素非常熱銷，1,000 張清單裡有 900 張都有買護髮素（Support = 90%）。

那麼「洗髮精 → 護髮素」的信賴度可能是 90%，看起來很高。但這不是因為洗髮精跟護髮素有什麼特別關聯，而是因為**護髮素本來就超受歡迎**，大家不管有沒有買洗髮精都會買它。

提升度就是用來排除這種「假象關聯」的。

### 計算公式

```
Lift(A → B) = Confidence(A → B) / Support(B)
```

也就是：在買了 A 的前提下買 B 的機率 ÷ 隨便一個人買 B 的機率。

### 帶入範例

```
Confidence(洗髮精 → 護髮素) = 50%
Support(護髮素) = 150 / 1,000 = 0.15（15%）

Lift(洗髮精 → 護髮素) = 0.5 / 0.15 ≈ 3.33
```

### 如何解讀提升度的數字？

| 提升度 | 意義 | 結論 |
|--------|------|------|
| > 1 | 買了 A 之後，買 B 的機率高於平均 | **正相關，值得搭售或推薦** |
| = 1 | A 和 B 互不影響，各自獨立 | 無關聯，不需要處理 |
| < 1 | 買了 A 之後，買 B 的機率反而低於平均 | **負相關，放在一起可能互相排擠** |

範例中 Lift ≈ **3.33**，代表「買了洗髮精的人，買護髮素的機率是一般人的 3.33 倍」——這是真實的強關聯，適合做套裝推薦。

---

## 三個指標的關係與使用順序

實際做購物籃分析時，三個指標是依序篩選的：

```
第一關：支持度 > 門檻值
   → 太罕見的組合直接丟掉（沒有商業意義）

第二關：信賴度 > 門檻值
   → 規則可靠度要夠高（買了 A 才有一定機率買 B）

第三關：提升度 > 1
   → 確認關聯是真實的，不是「兩個都熱銷」造成的假象
```

三關都過的商品組合，才是真正有價值、值得行動的「關聯規則」。

## 和投資研究的類比

這個方法如果套用到基金推薦，概念會變成：

- **支持度**：有多少投資人同時持有基金 A 和基金 B？
- **信賴度**：已知投資人持有基金 A，他也持有基金 B 的機率是多少？
- **提升度**：這個「一起持有」的關係是真實偏好，還是只是因為基金 B 本來就很熱門？

可以用來找出「哪些基金常被一起申購」，作為交叉推薦（cross-sell）的依據。
