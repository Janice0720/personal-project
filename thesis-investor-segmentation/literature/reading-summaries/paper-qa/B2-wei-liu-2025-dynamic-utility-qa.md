# B2 論文問答：架構白話流程解析
**論文**：Wei & Liu（2025）基於動態效用學習之個人化基金推薦

---

## 這篇論文在做什麼？一句話版本

> 系統**觀察你點了哪些基金、不點哪些**，從中學習你的偏好，下次再來就推薦你更可能喜歡的——同時偶爾丟幾檔「陌生基金」測試你，讓系統越學越準。

---

## 整體流程圖（簡化版）

```
第一次來訪
    │
    ▼
【系統完全不認識你】
    │ 隨機推薦幾檔基金
    ▼
【你點了幾檔你喜歡的】
    │ 系統收集：你點了什麼、點的順序
    ▼
【系統學習：你的喜好長什麼樣？】
    │ 建立一份「你的偏好分數公式」
    ▼
第二次來訪
    │
    ├─ 90% 機率 → 推薦公式算出來分數最高的基金（利用你已知的偏好）
    └─ 10% 機率 → 隨機推薦幾檔陌生基金（測試你、繼續學習）
    │
    ▼
【你又點了幾檔】
    │ 系統更新偏好公式
    ▼
第三次、第四次……（循環，越來越準）
```

---

## 拆解每一個步驟

---

### STEP 1：系統怎麼「描述一檔基金」？

論文用 **5 個數字**代表每一檔基金：

| 屬性 | 白話意思 |
|------|----------|
| 年化報酬 | 這檔基金過去一年賺了多少 % |
| 波動度 | 漲跌起伏大不大，越大越不穩 |
| 規模 | 基金管理的錢有多少 |
| 周轉率 | 基金經理人換股票換得多不多 |
| 排名 | 在同類型基金裡排第幾 |

每一檔基金都可以用這 5 個數字描述，就像一份「基金身分證」。

---

### STEP 2：系統怎麼「描述你的偏好」？

系統假設你的偏好可以用一個「打分公式」來表達：

```
你對某檔基金的喜好程度
= (你對報酬的重視程度 × 報酬)
+ (你對波動的厭惡程度 × 波動)
+ (你對規模的重視程度 × 規模)
+ (你對周轉率的在意程度 × 周轉率)
+ (你對排名的重視程度 × 排名)
```

舉例：如果你是積極型投資人，你的公式可能是：

```
分數 = 2×報酬 - 4×波動 + 10×規模 + 0×周轉率 - 2×排名
```

意思是：**你超重視規模（+10），非常討厭波動（-4），不在乎周轉率（0）**。

每個投資人的公式係數不同，系統要做的事，就是**從你的點擊行為裡，把你的專屬係數猜出來**。

---

### STEP 3：系統怎麼從「點擊」學習你的偏好？

系統收集你的點擊資訊，然後做出兩個判斷：

1. **你點的順序有意義**：先點的 > 後點的（先點 = 更喜歡）
2. **點 vs 不點有意義**：有點的 > 沒點的（點 = 喜歡，沒點 = 不喜歡）

然後系統去解一道數學題：

> 「哪一組係數，才能讓上面這些比大小的關係全部成立？」

**第一次**：完全從零開始猜係數。
**第二次之後**：在上一輪猜出來的係數基礎上，小幅調整讓新的點擊紀錄也能成立——**不會每次都全部重來，而是在舊答案上微調**。

這就是論文說的「增量學習」——每次互動只更新一點點，積累起來越來越準。

---

### STEP 4：下次推薦時，ε-greedy 怎麼運作？

每次推薦清單的每一個位置，系統都丟一枚「硬幣」決定怎麼填：

```
丟硬幣
 │
 ├── 正面（機率 1-ε，例如 90%）
 │     → 「利用」：從基金池裡挑目前分數最高的那一檔
 │       （用你的偏好公式算分，推薦你最可能喜歡的）
 │
 └── 反面（機率 ε，例如 10%）
       → 「探索」：從剩下的基金池裡隨機挑一檔
         （讓你看到陌生的選項，系統藉此繼續學習你的偏好）
```

**為什麼要「探索」？**

想像系統已經知道你喜歡穩定的大型基金，於是每次都推同類型。但你其實對科技型基金也有興趣，只是還沒遇到過。

如果系統永遠不探索，它就永遠不知道你還有這個偏好——會困在「以為已經完全了解你」的假象裡。

---

### STEP 5：ε 要設多大？有什麼差別？

| ε 值 | 探索比例 | 效果 |
|------|----------|------|
| ε = 0 | 完全不探索 | 推薦很快固定，但偏好學不完整，可能學到錯的就卡住了 |
| ε = 0.1 | 10% 探索 | **實驗表現最好**：大部分時間推你最可能喜歡的，偶爾探索保持學習 |
| ε = 0.5 | 50% 探索 | 學習較完整，但一半推薦是隨機的，顧客體驗下降 |
| ε = 1 | 100% 探索 | 什麼都亂推，完全沒有利用學到的偏好，體驗最差 |

**結論**：太貪心（ε=0）學不到完整偏好；太散漫（ε=1）推薦品質很差。**小幅探索（ε=0.1）是最佳平衡點。**

---

### STEP 6：如果你點錯了或漏點了怎麼辦？

真實情境中你可能手滑點錯、或沒看到某檔好基金——這樣你的點擊紀錄就互相矛盾（A>B 但又 B>A），系統解不出合理的係數。

論文的解法：**ICEA 迭代約束刪除演算法**

白話版：

```
發現矛盾
 │
 ▼
把矛盾的比大小約束分組
 │
 ▼
把造成衝突的那組先移除，用剩下的約束解看看
 │
 ▼
找到「移除最少約束、但能解出來」的方案
 │
 ▼
用這個最大可行的子集更新偏好公式，繼續運作
```

就是「把最少的矛盾衝突忽略掉，盡量保留有效的點擊資訊繼續學習」。

---

## 整個系統的一句話總結流程

```
看你點什麼 → 建立你的偏好公式 → 大部分時間推你最可能喜歡的
→ 偶爾推陌生基金探索你的新偏好 → 更新公式 → 循環，越來越準
```

## 和你論文的關聯

| B2 的概念 | 你的研究可以怎麼用 |
|----------|-------------------|
| 效用函數（偏好公式） | 投資人對基金屬性（報酬、風險、規模）的偏好，可以用同樣的「加權公式」量化 |
| 增量學習 | 投資人的偏好會隨時間改變（例如年輕時積極、年長後保守），支持「動態更新」的設計思路 |
| ε-greedy 探索–利用 | 新投資人（冷啟動）可以先多探索；老投資人（有歷史）可以多利用 |
| 冷啟動解法 | 第一次來的新投資人無歷史紀錄，就先隨機推薦，從互動中逐步學習——這是可行的新客推薦流程 |
