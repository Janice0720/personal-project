## 2. 研究背景與動機

- 衍生性商品市場（Derivatives Market）參與者行為複雜，不同類型投資人的交易動機、風險承受度與交易頻率差異顯著。
- 傳統投資人分類多依賴靜態屬性（如 KYC 問卷、開戶資料），缺乏以**實際交易行為資料**驅動的動態分群。
- 馬來西亞衍生性商品市場（Bursa Malaysia Derivatives）擁有龐大的高頻交易資料，提供了以大規模行為資料進行投資人輪廓建立（investor profiling）的難得實證機會。
- 金融監管與市場穩定的需求，使得理解「誰在交易、如何交易」成為市場設計與投資人保護的重要議題。

---

## 3. 研究目的與問題

### 3.1 研究目的

- 以 K-means 分群法，從馬來西亞衍生性商品市場的大規模交易紀錄中，自動識別具商業與行為意義的**投資人群體**。
- 建立每個群體的行為輪廓（behavioral profile），提供監管機構、交易所與投資教育機構的政策參考。

### 3.2 核心研究問題

1. 依據交易行為特徵，馬來西亞衍生性商品市場的投資人可分為哪幾類？
2. 各類投資人的交易行為特徵有何顯著差異？
3. K-means 分群結果是否具備解釋力與內部一致性？

## 5. 研究方法

### 5.1 整體流程

```
原始交易資料（1,100 萬筆）
   → 特徵工程（交易行為指標計算）
   → IHS 轉換（處理偏態分佈）
   → K-means 分群（選定最佳 K 值）
   → 分群結果詮釋（投資人輪廓命名）
   → Decision Tree 驗證（分群可解釋性驗證）
```

### 5.2 IHS 轉換（Inverse Hyperbolic Sine Transformation）

- 金融交易資料通常呈現嚴重右偏分佈（少數高頻大量交易者 vs. 多數低頻小量交易者），若直接使用原始數值進行分群，高值樣本將主導群心距離計算，導致分群偏差。
- IHS 轉換（`arcsinh(x)`）的特性：
  - 對零值與負值也能處理（不同於 log 轉換）
  - 能有效壓縮右尾極端值，使分佈接近常態
  - 保留變數間的相對大小關係
- 本研究選擇 IHS 而非 log 轉換的理由：金融交易資料含零值（未交易的時段或投資人），log(0) 未定義，IHS 可處理此邊界情況。

### 5.3 K-means 分群

- 採用標準 K-means 演算法，以歐氏距離計算群心距離。
- 最佳 K 值選取：以 Elbow Method、Silhouette Score、Davies-Bouldin Index、Calinski-Harabasz Index **四種指標綜合收斂判斷**（並非僅 Elbow+Silhouette 兩種），四項指標在 k=3 至 6 間收斂，於 **k=5** 時 Silhouette Score 達局部最大、Davies-Bouldin Index 達局部最小、Calinski-Harabasz Index 亦處高值，四項指標一致支持 k=5 為最適分群數。
- 分群對象：以**每位投資人（主鍵）**為分析單位，特徵向量為六項工程特徵。

## 6. 特徵設計

> **⚠️ 2026-09-26 修正**：以下內容經核對原文 Table 2「Formulated engineered features」逐項更正，原版本特徵清單（交易頻率、交易量、合約類型、買賣方向、持倉行為）**與原文不符**，屬誤植。

原文實際使用之六項工程特徵（依投資人主鍵彙整）：

| 特徵名稱 | 說明 |
|----------|------|
| Total Number of Trades（總交易筆數） | 該投資人在期間內的交易總筆數 |
| Total Traded Amount（總交易金額） | 該投資人買賣交易金額之加總 |
| Overall Realized Profit（總已實現損益） | 已配對交易之賣出金額減買入金額，正值為獲利、負值為虧損 |
| Average ROI（平均投資報酬率） | 已實現損益除以已配對交易之買入總金額，為標準化獲利指標 |
| Maximum Account Vintage（帳戶年資） | 帳戶最後交易日期與開戶日期之差（以年計） |
| Median Holding Days（持倉天數中位數） | 已配對交易之買賣間隔天數中位數，反映典型持倉時間 |

另有五個**類別變數**（非用於分群，僅供分群結果之交叉特徵描述）：投資人類型（Retail／RTIP／Local）、性別、年齡層、交易商品偏好（FCPO／FKLI dominant／favored／neutral）、主要交易策略類型（SPD／NRM）。

## 7. 分群結果與投資人輪廓

> **⚠️ 2026-09-26 修正**：原版本之群體命名（高頻積極型、低頻保守型等）為研讀者臆測之示意內容，並非原文實際結果，已依原文 Results and Discussion 一節全面更正。

原文以決策樹分類器之切分條件為各群命名，k=5 之分群結果如下：

| 群體 | 占比 | 命名（原文） | 主要特徵（決策樹切分條件） |
|------|------|------|-----------------------------|
| Cluster 1 | 20.4% | High-Frequency, High-Risk Derivative Traders with Consistent Losses（高頻高風險、持續虧損型） | 總已實現損益 < RM −51.85 千、總交易金額 > RM 1,757 萬、持倉天數中位數 < 2.22 天 |
| Cluster 2 | 14.6% | Conservative, Steady-Growth Derivative Traders（保守穩健成長型） | 平均 ROI > 0.139%、持倉天數中位數 > 0.299 天、總交易筆數 < 364.5 筆 |
| Cluster 3 | 21.1% | High-Frequency, High-Yield Derivative Traders（高頻高獲利型） | 總已實現損益 > RM 40.938 千、總交易金額 > RM 1,588.2 萬、持倉天數中位數 < 0.993 天 |
| Cluster 4 | 12.0% | Conservative, Low-Yield Derivative Traders（保守低獲利型） | 平均 ROI < −0.205%、持倉天數中位數 > 0.203 天、總交易筆數 < 306.5 筆 |
| Cluster 5 | 31.9%（最大群） | Cautious, Low-Activity Novice Derivative Traders（謹慎低活躍新手型） | 總交易筆數 < 156.5 筆、持倉天數中位數 < 0.068 天、帳戶年資 < 3.337 年、總已實現損益 < RM 40.487 千 |

補充觀察：Cluster 5（占比最大，31.9%）以年輕投資人（18–25、26–35 歲）與帳戶年資較短者為主，作者推論為新手／低涉入投資人；Retail 投資人類型在所有群體中占比皆逾 97%。

## 8. 模型驗證方式

### 8.1 決策樹驗證（Decision Tree Validation）

- 以 K-means 分群標籤作為目標變數，訓練一棵**決策樹分類器**。
- 若決策樹能以少數特徵高準確率重現分群結果，代表分群具備**可解釋性**與**內部一致性**。
- 此驗證方式同時產出各特徵的重要性排名（Feature Importance），協助理解哪些行為指標最能區分投資人類型。

### 8.2 Silhouette Score

- 衡量分群內部緊密度與群間分離度，確認 K 值選擇的合理性。

---

## 9. 研究結論

1. K-means 結合 IHS 轉換能有效從大規模金融交易資料中識別出行為差異顯著的投資人群體。
2. 各群投資人在交易頻率、量與方向性上呈現明確分化，具備商業詮釋意義。
3. 決策樹驗證確認分群結果具可解釋性，且少數核心特徵即可有效區分群體。
4. IHS 轉換對金融偏態資料的前處理至關重要，可有效提升分群品質。

---

## 10. 研究限制

- 資料來源為單一市場（馬來西亞衍生性商品），分群結果是否可跨市場（如台灣共同基金市場）遷移，需進一步驗證。
- 衍生性商品與共同基金在投資人行為特性上存在差異（如持倉時間、進出場機制），不能直接套用，需調整特徵設計。
- K-means 假設各群為球形分佈，若投資人行為資料存在非球形群簇，分群效果可能受限。
- 靜態分群未考量投資人行為隨時間的動態演變。
