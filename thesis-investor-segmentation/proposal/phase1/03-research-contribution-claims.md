# 本研究貢獻主張

論文題目：應用投資人行為分群與個人化推薦模型於數位券商基金投資服務之研究

本文件依據前置文獻脈絡與研究缺口，整理本研究可於 proposal 中審慎主張之研究貢獻。整體而言，本研究不宜宣稱其主要貢獻為演算法創新，而較適合定位為「資料整合、場域實證與可評估推薦流程之應用型研究」。亦即，本研究的價值在於：於台灣數位券商基金投資服務場域中，整合網站行為資料與基金交易資料，建立投資人行為分群，並進一步比較個人化推薦模型與熱門基金推薦 baseline 之差異，以補足既有文獻在資料來源、研究場域、分群與推薦銜接，以及基準模型比較上的不足。

---

## 一、理論或文獻貢獻

### 1. 回應投資人行為研究中「交易結果偏重」之不足

既有投資人行為、顧客分群與基金推薦研究，多以交易紀錄、人口統計變數、風險屬性、投資組合資料或問卷資料作為主要分析基礎。此類資料能反映投資人已完成之投資決策，卻較難完整呈現投資人在交易前的資訊搜尋、商品瀏覽、基金比較與興趣形成過程。

本研究若整合 GA4 網站行為資料與基金交易資料，可在文獻上補充「交易前行為」與「交易結果」之間的銜接觀點。具體而言，網站行為資料可反映投資人如何接觸基金資訊，例如瀏覽基金頁面、搜尋基金關鍵字、停留時間、回訪頻率與行動裝置使用比例；交易資料則反映其實際申購、贖回與基金偏好。此設計可使投資人行為研究不僅回答「投資人買了什麼」，也能進一步討論「投資人在購買前如何形成興趣與偏好」。

### 2. 補足分群文獻與推薦系統文獻之銜接不足

顧客分群文獻常強調透過 RFM、機器學習分群或顧客價值分析辨識不同客群；推薦系統文獻則關注如何根據使用者—商品互動產生個人化推薦。然而，兩類文獻有時分別發展：分群研究可能停留在客群描述與行銷策略建議，推薦研究則可能直接進入模型比較，而較少將「投資人行為分群」作為推薦模型設計或評估的中介環節。

本研究將投資人分群與基金推薦模型放在同一研究架構中，可補充此一連結。分群結果不僅用於描述投資人輪廓，也可進一步作為推薦模型之輔助特徵、分層策略或群體別成效分析基礎。此一設計有助於說明分群在數位券商基金服務中不只是分類工具，而是連結投資人異質性與個人化推薦策略的重要橋樑。

### 3. 凸顯金融商品推薦不同於一般電商推薦之研究脈絡

一般推薦系統研究多以點擊率、購買率或使用者黏著度作為主要目標，但基金與金融商品推薦涉及風險屬性、投資人適合度、資訊揭露與投資人保護，不能完全套用一般電商推薦邏輯。本研究聚焦數位券商基金投資服務，可在文獻回顧中進一步強化金融商品推薦的特殊性。

本研究可將基金推薦定位為「在風險與適合度約束下的個人化資訊排序」，而非單純預測最可能成交的商品。此一定位有助於將推薦系統文獻、基金推薦文獻、FinTech 應用研究與投資人保護議題加以整合，形成較符合金融服務情境的理論論述。

### 4. 補充台灣數位券商基金投資服務之在地化文獻

既有國際基金推薦與金融商品推薦研究雖已提出協同過濾、圖模型、基金相似度、動態偏好學習與可解釋推薦等方法，但其資料來源、市場制度、投資人行為與平台情境未必能直接對應台灣數位券商。台灣本土研究雖已有券商推薦、機器人理財採用、共同基金投資行為與風險偏好等研究脈絡，但較少直接聚焦於數位券商平台之基金投資服務，並以平台行為資料與交易資料建立分群及推薦模型。

因此，本研究可主張其文獻貢獻在於補充台灣數位券商基金服務場域下的實證研究，使相關文獻由一般金融科技採用或傳統基金投資行為，延伸至資料驅動之投資人分群與個人化基金推薦應用。

## 二、方法貢獻

### 1. 建立網站行為資料與交易資料之雙軌資料整合流程

本研究的方法貢獻之一，在於建立一套可操作的雙軌資料整合流程。交易資料可建構申購次數、交易金額、最近交易天數、基金類型偏好、基金多樣性與買賣比例等變數；網站行為資料則可建構 session_count、fund_page_views、search_count、avg_session_duration、last_visit_days、mobile_ratio 等行為特徵。兩類資料分別對應投資決策歷程中的「實際交易結果」與「交易前互動訊號」。

相較於僅依交易資料建立投資人輪廓，此方法可納入高瀏覽但低交易、頻繁搜尋但尚未申購、或對特定基金類型高度關注但尚未轉換之投資人。相較於僅依網站行為資料進行分析，交易資料又能提供較強的實際偏好訊號。因此，雙軌整合有助於降低單一資料來源造成的解釋限制。

### 2. 將交易 RFM 與行為 RFM 概念延伸至基金投資服務

本研究可將 RFM 概念由一般零售購買行為延伸至基金投資服務。交易 RFM 可用於衡量投資人最近交易時間、交易頻率與交易金額；行為 RFM 則可用於衡量最近造訪或瀏覽時間、網站互動頻率與基金資訊接觸深度。此設計兼具理論可解釋性與實務可操作性。

若後續以 K-means、GMM、階層分群或其他非監督式學習方法建立投資人分群，本研究可進一步透過 Silhouette score、Davies-Bouldin Index、群體特徵均值與業務可解釋性檢查，選擇較合理之分群結果。此方法貢獻不在於提出全新分群演算法，而在於將既有 RFM 與機器學習分群方法轉化為適用於數位券商基金投資服務的研究流程。

### 3. 建立由分群銜接推薦之漸進式模型比較架構

本研究可採取「熱門基金推薦 baseline → User-based CF → Item-based CF → SVD → 分群輔助推薦」的漸進式模型比較設計。此設計具備兩項方法優點：第一，可避免直接使用複雜模型而缺乏比較基準；第二，可逐步檢驗個人化資訊、協同過濾訊號、矩陣分解與分群資訊是否帶來增量效果。

其中，分群輔助推薦可有數種設計方式，例如將分群標籤作為模型特徵、於同一群體內計算基金偏好、針對不同群體建立不同候選基金清單，或進行分群別 Top-K 推薦成效分析。無論採取何種設計，本研究皆可透過模型比較說明「投資人分群是否能提升基金推薦表現」，而非僅停留在分群結果描述。

### 4. 以熱門推薦作為明確 baseline，強化模型評估之可解釋性

在數位平台實務中，熱門基金、最多人申購、近期績效排行或全站一致推薦，是相對容易部署且常見的推薦方式。因此，本研究將熱門基金推薦設定為 popularity-based baseline，並與個人化推薦及分群輔助推薦進行比較，可使模型評估更貼近平台實務問題。

具體而言，熱門推薦 baseline 可依訓練期間申購人數、申購次數或申購金額排序，對所有測試投資人推薦相同 Top-K 基金；個人化模型則依個別投資人歷史互動與相似使用者或相似基金產生推薦。若個人化模型優於 baseline，可支持其資料整合與模型建置成本具備合理性；若提升有限，亦能形成有價值的研究發現，說明在特定基金服務場景中，簡單推薦策略可能已具一定效果。

### 5. 採用 Top-K 評估指標對應實際推薦清單情境

本研究若使用 Precision@K、Recall@K、MAP 或 NDCG 等 Top-K 指標，可更符合數位券商介面中「推薦清單」的實際使用情境。相較於僅用 MAE 或 RMSE 衡量預測誤差，Top-K 指標能直接檢驗推薦清單前幾名是否命中投資人後續實際申購基金。

此外，若進一步進行分群別評估，本研究可分析不同投資人群體中，個人化推薦相較於熱門推薦的改善幅度是否不同。例如，對高活躍投資人，個人化模型可能因歷史互動較豐富而較有效；對新手或低交易投資人，熱門推薦或風險適配清單可能反而更穩定。此類分析可增加研究結果之方法深度與實務洞察。

## 三、實務應用貢獻

### 1. 協助數位券商由商品導向轉向投資人行為導向服務

數位券商基金服務若僅依熱門商品、基金績效或全站一致版位呈現基金，容易忽略投資人之異質性。本研究透過投資人行為分群與個人化推薦模型，可協助平台從「展示商品」轉向「理解投資人行為並提供差異化資訊」。

具體而言，平台可根據分群結果辨識不同投資人輪廓，例如高交易活躍型、瀏覽活躍但低轉換型、穩健長期持有型、潛力新手型或沉睡客戶型。不同群體可對應不同服務策略：對高活躍投資人可提供更精細的基金比較與相似基金推薦；對瀏覽活躍但低轉換者可提供教育內容或風險說明；對新手投資人則可提供低門檻、風險揭露清楚的基金探索輔助。

### 2. 提供基金推薦服務設計與成效評估依據

本研究將熱門推薦與個人化推薦進行比較，可為數位券商判斷推薦系統投入價值提供依據。若分群輔助或個人化推薦能在 Precision@K、Recall@K 或 MAP 上顯著優於熱門推薦，平台即可更有理由投入資料整合、模型維運與推薦介面設計；若差異有限，平台亦可重新檢視資料品質、模型設計、投資人群體差異或推薦目標設定。

因此，本研究的實務貢獻不僅是提出一個推薦模型，而是提供一套可評估的決策框架：平台可依據模型相對 baseline 的增量效果，判斷個人化推薦是否值得導入、應優先用於哪些投資人群體，以及如何調整基金推薦策略。

### 3. 降低投資人資訊搜尋成本並提升基金探索效率

基金商品通常具有類型、風險等級、投資區域、幣別、費用率與績效等多重資訊，對一般投資人而言容易形成資訊過載。本研究若能根據投資人行為與歷史交易偏好提供較相關之基金清單，理論上有助於降低基金搜尋與比較成本。

需要注意的是，本研究不應宣稱推薦模型必然提升投資報酬或替代投資顧問判斷；較審慎的主張是：個人化推薦可作為基金探索與資訊排序工具，協助投資人更有效率地接觸可能相關的基金資訊，並作為平台改善使用者體驗與資訊呈現之依據。

### 4. 支援更負責任的金融商品推薦治理

由於基金推薦涉及風險與適合度，本研究可將實務貢獻延伸至推薦治理層面。平台在建立個人化推薦時，不應僅以申購機率或轉換率作為唯一目標，而應納入風險等級、KYC 適合度、商品集中度與可解釋性等考量。

即使本研究初期模型以推薦準確度作為主要評估指標，仍可在 proposal 中說明後續可將基金風險等級、投資人風險屬性或候選基金篩選規則納入推薦流程。此一設計有助於使推薦模型更符合金融服務中的投資人保護與合規期待。

## 四、台灣數位券商或基金投資服務場域貢獻

### 1. 補足台灣數位券商真實平台資料應用之實證不足

台灣本土金融研究雖已涵蓋共同基金投資行為、投資人風險偏好、券商推薦資訊內涵、機器人理財採用與數位理財服務接受度，但直接使用數位券商平台行為資料與基金交易資料，建立投資人分群及推薦模型之研究仍相對有限。

本研究若能以台灣數位券商場域之匿名化資料進行實證，可補充本土文獻在數位平台資料應用上的不足。此貢獻並非主張研究結果可直接外推至所有市場，而是提供一個具在地脈絡的實證案例，說明台灣數位券商如何運用既有平台資料改善基金投資服務。

### 2. 回應台灣基金投資服務之數位轉型需求

隨著投資服務逐漸由線下理專、銀行通路或傳統券商櫃檯，轉向 App 與網站等數位介面，基金投資服務不再只是交易執行問題，也涉及基金探索、資訊呈現、投資人教育與推薦排序。本研究聚焦數位券商基金服務，可回應台灣金融服務數位轉型下，如何以資料驅動方式理解投資人並提供個人化服務之需求。

特別是對基金商品而言，投資人可能在申購前經歷多次瀏覽、搜尋、比較與觀望。若平台能將這些行為訊號納入分群與推薦設計，將有助於更貼近數位投資服務的實際使用歷程。

### 3. 建立適合台灣數位券商情境的 baseline 比較觀點

在台灣數位券商或基金平台中，熱門基金、績效排行、主題基金清單或全站一致推薦常是實務上較容易部署的方式。本研究明確將熱門推薦設為 baseline，可使研究結果直接回答實務管理問題：在台灣數位券商基金服務中，個人化推薦相較於熱門基金清單是否具有可觀察的增量效果？

此一比較有助於避免單純展示模型準確率，而能將研究結果轉化為平台可理解的決策依據。若個人化推薦對某些投資人分群特別有效，平台可優先針對該群體導入個人化服務；若熱門推薦在某些群體已足夠，平台則可將模型資源配置於更需要個人化支持的投資人。

### 4. 提供台灣金融機構導入 AI 推薦時的審慎參考

本研究的場域貢獻亦在於提供台灣金融機構導入 AI 或資料驅動推薦時的審慎參考。相較於直接追求深度學習或複雜黑箱模型，本研究採用可解釋的分群、協同過濾、矩陣分解與熱門 baseline 比較，可較符合碩士論文可完成性，也較容易被金融服務實務端理解與檢視。

此一設計可作為台灣數位券商在導入基金推薦系統前的初步驗證框架：先確認資料是否足以支撐投資人分群，再比較個人化推薦是否優於簡單熱門推薦，最後再討論是否需要導入更複雜模型、風險適合度檢核或即時推薦機制。

## 五、依研究設計元素對應之具體貢獻

### 1. 整合網站行為資料與交易資料

可形成的具體貢獻包括：

- 在理論上，補充既有研究偏重交易結果而較少觀察交易前數位互動歷程之不足。
- 在方法上，建立基金投資服務中「平台行為特徵＋交易特徵」的雙軌特徵工程流程。
- 在實務上，協助數位券商辨識高瀏覽低交易、頻繁搜尋、潛在轉換或高活躍投資人等更細緻的行為型態。
- 在場域上，呈現台灣數位券商可如何使用 GA4 行為資料與內部交易資料進行資料驅動服務設計。

### 2. 使用投資人分群

可形成的具體貢獻包括：

- 在理論上，將投資人異質性由抽象概念轉化為可觀察、可描述的行為群體。
- 在方法上，將 RFM、網站互動特徵與機器學習分群結合，形成可解釋的投資人分群流程。
- 在實務上，提供平台進行差異化服務、基金資訊呈現、投資人教育與推薦策略分層之依據。
- 在推薦模型上，提供分群輔助推薦與分群別成效分析的基礎，使研究能檢驗不同投資人群體中模型效果是否有所差異。

### 3. 建立個人化推薦模型

可形成的具體貢獻包括：

- 在理論上，將一般推薦系統方法轉化至基金投資服務情境，並強調金融商品推薦需考量風險與適合度。
- 在方法上，建立 User-based CF、Item-based CF、SVD 或分群輔助推薦等可比較模型，形成漸進式推薦架構。
- 在實務上，提供基金探索、相似基金推薦、個人化基金清單與分群化服務之初步模型基礎。
- 在治理上，提醒基金推薦不應被視為單純銷售轉換工具，而應定位為協助投資人理解與篩選基金資訊的輔助機制。

### 4. 與熱門推薦 baseline 比較

可形成的具體貢獻包括：

- 在理論上，補足既有研究較少明確比較個人化推薦與平台常見熱門推薦策略之不足。
- 在方法上，以 popularity-based baseline 作為最低比較基準，使模型成效評估更具可解釋性。
- 在實務上，協助數位券商判斷個人化模型相較於熱門榜單、績效排行或全站一致推薦是否具備增量價值。
- 在研究結果詮釋上，若個人化模型表現較佳，可支持導入分群與推薦模型；若表現有限，亦可形成具價值的負面或限制性發現，提醒平台重新檢視資料品質、模型設計或使用情境。

## 六、可放入 proposal 的研究貢獻段落

本研究預期可在理論、方法與實務應用上提供以下貢獻。首先，在理論與文獻層面，既有投資人行為、顧客分群與基金推薦研究多偏重交易紀錄、靜態屬性或問卷資料，較少同時納入數位平台上的瀏覽、搜尋與互動行為；本研究透過整合 GA4 網站行為資料與基金交易資料，可補充投資人從資訊搜尋、基金瀏覽到實際申購之完整行為歷程，並將投資人異質性與個人化基金推薦之研究脈絡加以銜接。其次，在方法層面，本研究擬建立交易特徵與網站行為特徵之雙軌特徵工程流程，並以投資人行為分群作為推薦模型設計與分群別成效分析之基礎；同時，透過熱門基金推薦、協同過濾、矩陣分解與分群輔助推薦之比較，檢驗個人化推薦相較於簡單 baseline 的增量效果。第三，在實務層面，本研究可協助數位券商由全站一致或熱門基金導向之推薦方式，逐步轉向依據投資人行為輪廓提供差異化基金資訊與推薦服務，進而降低投資人資訊搜尋成本並提升基金探索效率。最後，在台灣數位券商場域層面，本研究以台灣數位券商基金投資服務為研究情境，補足本土文獻中較少使用真實平台行為資料與基金交易資料建立投資人分群及推薦模型之不足，並提供金融機構導入資料驅動基金推薦時可參考之審慎實證框架。

## 七、較精簡的 proposal 條列版本

1. 理論或文獻貢獻：本研究整合投資人行為、顧客分群、RFM、推薦系統、基金推薦與 FinTech 文獻，補足既有研究較少同時觀察網站行為資料與基金交易資料之不足，並強化金融商品推薦不同於一般電商推薦的理論定位。

2. 方法貢獻：本研究建立網站行為特徵與基金交易特徵之雙軌資料整合流程，將交易 RFM 與行為 RFM 概念應用於投資人分群，並透過熱門推薦、協同過濾、矩陣分解與分群輔助推薦之漸進式比較，檢驗各模型之推薦成效。

3. 實務應用貢獻：本研究可協助數位券商辨識不同投資人行為群體，並評估個人化推薦相較於熱門基金推薦之增量價值，作為基金探索、差異化服務、推薦介面設計與投資人教育內容規劃之參考。

4. 台灣數位券商與基金投資服務場域貢獻：本研究聚焦台灣數位券商基金投資服務，使用匿名化平台行為資料與基金交易資料進行實證，可補足台灣本土文獻在數位券商資料驅動基金推薦應用上的不足，並提供金融機構導入個人化推薦時兼顧可解釋性、適合度與投資人保護之初步參考。

## 八、建議使用時的審慎表述

為避免 proposal 中過度宣稱，建議使用以下語氣：

- 可主張：「本研究可補充既有文獻在台灣數位券商基金投資服務場域之實證不足。」
- 可主張：「本研究有助於檢驗個人化推薦相較於熱門推薦 baseline 是否具備增量效果。」
- 可主張：「本研究提供一套可操作、可解釋且可評估的分群與推薦流程。」
- 應避免：「本研究提出全新推薦演算法。」除非後續確實設計新演算法。
- 應避免：「本研究必然提升投資報酬。」推薦模型只能支援資訊排序與基金探索，不能保證投資績效。
- 應避免：「本研究結果可代表所有台灣投資人。」較審慎的說法是，本研究提供特定數位券商場域下之實證案例與方法參考。
