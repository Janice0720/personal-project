# 3.7 模型評估方法

> **使用狀態：** 本節為第三章 3.7 節正式草稿，2026-09-26 依 `01-research-design-and-evaluation.md` §3.7 之定案推理改寫為正式章節文字。訓練／測試集時間切分原則、評估指標選用（Precision@K、Recall@K、MAP）為方法論層級承諾；RQ3 群體間差異之統計檢定方法則改寫為決策準則，依實際資料之常態性檢定結果決定採用無母數或母數方法，詳見文末「計畫階段說明」。

## 3.7.1 訓練集／測試集切分方式

本研究規劃依時間切分訓練期與測試期（例如以前 10–14 個月資料為訓練期、最後 2–4 個月資料為測試期），採**時間切分而非隨機切分**。採此設計之理由為：真實推薦情境必然是「以過去已發生之資料，推薦尚未發生之未來行為」，若採隨機切分，測試集中可能包含訓練期之後才產生之市場資訊或使用者行為模式，導致模型在訓練階段間接取得「未來」資訊，形成資料洩漏（data leakage），使評估結果高估模型之實際預測能力。

**評估對象範圍：** 僅納入「訓練期與測試期皆有交易紀錄」之使用者。測試期無交易紀錄之使用者，其 Recall 分母為零，無法計算；訓練期無交易紀錄之使用者（純新戶）則屬冷啟動（cold-start）情境，缺乏歷史互動資料可供 ALS 學習，故不納入主要評估範圍，另列為第五章研究限制。

## 3.7.2 評估指標定義與計算方式

本研究採用 **Precision@K**、**Recall@K**、**MAP（Mean Average Precision）** 三項資訊檢索領域常用指標評估各模型之推薦成效（Manning, Raghavan, & Schütze, 2008）。以單一使用者、K = 5 為例：若模型推薦之 Top-5 清單為基金 A／B／C／D／E，該使用者測試期實際購買 B／E／F（共 3 檔），則：

- **Precision@K** = 命中數 ÷ K = 2 ÷ 5 = 0.4，代表推薦清單中命中使用者實際購買之比例。
- **Recall@K** = 命中數 ÷ 使用者實際購買數 = 2 ÷ 3 ≈ 0.67，代表使用者實際購買中被推薦到之比例。
- **MAP（Mean Average Precision）**：在 Precision 之基礎上，額外考慮命中項目於推薦清單中之排序位置，命中項目排序愈靠前，分數愈高，符合使用者較關注清單前段內容之真實情境。

**計算流程（對每個模型重複執行）：**

```
for 每位使用者 in 評估範圍使用者:
    推薦清單 = 模型.產出TopK(使用者, K)
    實際購買 = 測試期資料[使用者的所有 fund_code]
    命中數 = 推薦清單 與 實際購買 的交集數量
    該使用者_Precision = 命中數 / K
    該使用者_Recall = 命中數 / len(實際購買)

最終 Precision@K = 所有使用者之 該使用者_Precision 取平均
最終 Recall@K = 所有使用者之 該使用者_Recall 取平均
```

MAP 依相同架構，改以 Average Precision 為單位取平均。實作規劃採 Python `recmetrics` 套件之現成函式。

**所需資料欄位（僅需交易紀錄）：**

| 欄位 | 說明 |
|---|---|
| user_id | 使用者識別碼（匿名化） |
| fund_code | 基金代碼 |
| transaction_date | 交易日期（買入） |
| （可選）amount | 交易金額；除用於加權版評估指標外，若資料完整度允許，亦作為 3.6.4 節 ALS 信賴權重 $c_{ui} = 1 + \alpha r_{ui}$ 之觀察強度 $r_{ui}$ 來源，替代預設之購買次數 |

## 3.7.3 分數之意義與模型間比較邏輯

單一指標數值本身並無絕對之好壞標準：本研究之基金型錄約達 4,000+ 檔，使用者於測試期之購買數量通常僅為個位數，Precision@K 之分母天生受限，即使為理想模型，數值亦不會接近 1；業界推薦系統於此類指標之常態表現多落於 0.1–0.2 區間。

本研究之核心論證邏輯為模型間之**相對比較**，而非單一數值之絕對高低：分群輔助 CF 之指標分數，是否顯著高於熱門推薦、內容導向推薦、純 ALS CF 三個基準模型？若四模型分數呈遞增趨勢，且差異經統計檢定（成對 t 檢定或 Wilcoxon 符號等級檢定，比較同一批使用者在不同模型下之分數）證實顯著，即可回答研究問題 RQ2：「分群輔助之個人化推薦，相較基準模型具有統計上顯著之增量效果」，此為全論文最核心之研究發現。

## 3.7.4 RQ3 群體間差異之計算方式

為回答研究問題 RQ3「分群輔助帶來之效果提升，是否因投資人群體而異」，規劃計算方式如下：

1. 對每位使用者計算 **Δ 值** = 分群輔助 CF 分數 − 純 ALS baseline 分數（Precision@K、Recall@K、MAP 各自計算），代表該使用者因分群輔助獲得之效果提升幅度，而非單純比較各群體之絕對分數高低。
2. 依 3.5 節分群標籤，將使用者之 Δ 值依所屬群體分組。
3. **統計檢定方法之決策準則：** 投資交易資料常呈右偏分布（少數使用者交易頻率／金額遠高於多數人），故預期採用不要求常態假設之 **Kruskal-Wallis 檢定**（Kruskal & Wallis, 1952）為主要方法，比較各群體 Δ 值排名是否具顯著差異。實際取得資料後，將先執行常態性檢定（如 Shapiro-Wilk 檢定；Shapiro & Wilk, 1965），若 Δ 值分布符合常態假設，則改採統計檢定力較高之 ANOVA 或 Welch's ANOVA（Welch, 1951）；若不符合常態假設，則維持 Kruskal-Wallis 檢定。
4. 整體檢定顯著時，以對應之事後檢定找出具體哪些群體間差異顯著：無母數情境採 **Dunn's test**（Dunn, 1964）；母數情境依變異數是否同質，採 **Tukey HSD**（Tukey, 1949，變異數同質時）或 **Games-Howell**（Games & Howell, 1976，變異數不同質時）。據此回答「哪一類投資人從分群輔助推薦中受益最多」，作為好好證券未來個人化推薦資源優先分配之實務建議依據（對應第五章 5.3 實務應用建議）。

## 計畫階段說明

本節所述之訓練／測試集時間切分原則、評估對象範圍界定，以及 Precision@K、Recall@K、MAP 三項評估指標之選用，係根據推薦系統評估之標準實務與避免資料洩漏之方法論考量所作之決策，為本研究之核心承諾，預期不因實際資料結果而調整。

RQ3 群體間差異之統計檢定方法，則規劃為一組**決策準則**而非單一定案方法：主要依據 Δ 值分布之常態性檢定結果，於 Kruskal-Wallis 檢定與 ANOVA／Welch's ANOVA 之間擇一，並搭配對應之事後檢定。此設計使本研究得以在取得實際資料後，依資料實際分布特性選擇統計檢定力最適當之方法，相關選擇過程與結果將於第四章實驗結果完整記錄，不視為偏離計畫書。

> **待辦（文獻）**：需於文獻回顧補入 Kruskal-Wallis 檢定或 ANOVA 於分群／客群比較情境之應用文獻，佐證方法選擇合理性，可優先查詢 `literature-matrix.md` 中既有分群相關文獻（如 A6、A7、G1）是否已採用此類檢定，或另行查找無母數檢定於顧客分群成效比較之應用案例。
