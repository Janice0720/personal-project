# 06 校外協助與立委陳情

本資料夾用來存放校外協助與行政救濟路線圖，以及準備對教育部、立法委員、監察院或其他外部單位寄送的案件摘要、陳情書、附件目錄及公開版資料。原始證據仍保留在其他主題資料夾，不搬入或重複修改。

## 現有文件

- `校外協助與行政救濟路線圖.md`：整理教育部陳情、資訊公開申請、立委陳情、訴願、行政訴訟、法扶、監察院及公共倡議等管道，並標示先後順序與期限風險。

## 如何辨別

- `draft`：尚在修改的草稿。
- `final`：確認內容後的正式版本。
- `public`：已遮蔽姓名、學號、電子郵件等個資的公開版本。
- `attachment_list`：陳情所附證據的編號與名稱清單。

對外文件應引用 `00_project_tracker/evidence_index.md` 中的證據編號，並清楚區分已證實事實、合理疑義及請求調查事項。
