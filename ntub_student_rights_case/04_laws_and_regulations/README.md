# 04 法規與校內規章

本資料夾保存正式法規、教育部函文、北商校內規章，以及直接供本案申訴使用的法規摘要、法律分析與申訴書草案。

## 如何辨別

- `L-xxx`：法律、教育部法規或校內規章。
- 檔名格式建議為 `L-編號_發布或修訂日期_規章簡稱.pdf`。
- 同一規章有不同版本時，保留每個版本並在檔名標示日期，不覆寫舊檔。

## 現有檔案

- `L-002_NTUB_student_appeal_rules.pdf`：北商《學生申訴處理辦法》官方PDF，教育部2023-01-19核定版本。
- `L-002_學生申訴程序摘要.md`：申訴範圍、30日期限、學校處理期限、後續訴願及本案適用重點。
- `L-004_會議附件公開與學生知情救濟權分析.md`：說明附件未上網不當然違法，但關鍵附件未公開或未提供如何妨礙知情、核對決議及申訴，並整理資訊申請與部分公開依據。
- `L-005_一般學生申訴管道透明度與程序可近性分析.md`：查核一般學生申訴頁面缺少明確窗口、送件方式及專用格式的情況，並整理對30日期限、收件舉證及有效救濟的影響。
- `北商學生內部申訴書_草案.md`：整合畢業學分、人工智慧課程收費及證照補助三項爭議的校內申訴書草案；送件前須完成標示欄位並確認正式決定與30日期限。
