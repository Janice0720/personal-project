# 03 人工智慧課程與學分費

本資料夾保存「人工智慧與決策應用研討」的課程、收費及實際教學證據。檔案直接放在本層，以證據編號和檔名辨別種類。

## 如何辨別

- `C-xxx`：課程表、註冊須知、收費標準、教學大綱等官方資料。
- `C-Uxx`：使用者提供的選課畫面、繳費單、課程平台、通知或未授課佐證。
- 檔名含 `registration_notice`：註冊及收費依據。
- 檔名應包含學年度或證據日期，避免不同學期混淆。
