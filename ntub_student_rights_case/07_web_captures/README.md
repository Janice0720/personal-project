# 07 官方網頁截圖

本資料夾保存官方網站在特定日期的畫面證據，用來證明當時網站顯示的標題、日期、附件或公告狀態。

## 如何辨別

- 檔名開頭沿用原證據編號，例如 `B-001` 表示與證照補助證據 B-001 相對應。
- 檔名結尾說明截圖內容，例如 `certificate_subsidy_announcement`。
- 截圖應盡量包含網址列、頁面標題、公告日期及關鍵文字。
