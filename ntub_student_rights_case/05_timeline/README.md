# 05 統一事件時間軸

本資料夾把畢業學分、證照補助及課程收費三條證據線依日期排列，方便看出事件先後。

## 如何辨別

- `master_timeline.md`：全案主要時間軸，並逐證據線列出「已補齊、仍待補、資料矛盾」及整體完整性結論。
- 每個事件都應附證據編號，例如 `A-003`、`B-U01` 或 `C-002`。
- 「官方文件」「使用者提供」「尚待查證」應分別註明，避免把疑義寫成已確定事實。

新增具有日期意義的證據後，應同步更新 `master_timeline.md`。

若文件已取得，應把狀態改為「已確認」；若只有部分原檔、附件未公開或不同資料互相矛盾，應保留「部分確認」或「資料矛盾」，不可僅因已有一份相關文件就標示全部補齊。
