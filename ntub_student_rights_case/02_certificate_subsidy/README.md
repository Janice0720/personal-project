# 02 證照補助爭議

本資料夾集中保存證照補助規定、官方公告畫面與個人申請資料。為方便閱讀，所有檔案直接放在本層，不再分成公告、現行規定、舊版規定及個人證據等子資料夾。

## 如何辨別

- `B-xxx`：校方公告、補助規定及官方網頁留存。
- `B-Uxx`：使用者提供的信件、申請表、證書或對話紀錄；`U` 代表 user evidence。
- 檔名含 `dom_snapshot`：官方網頁的文字／頁面結構留存。
- 檔名含日期或版本號：該規定的修訂日期或證據發生日期。

- `B事件說明與時間軸.md`：本案從申請、助教收悉與補正，到所務會議修訂及官方公告的完整事件說明；進入本資料夾時建議先閱讀此檔。
- `B-001_1150623_current_rules.pdf`：115 年 6 月 23 日修訂的證照補助規定。

新增資料時，官方資料使用下一個 `B-xxx`；個人資料使用下一個 `B-Uxx`，並同步更新 `00_project_tracker/` 中的索引及來源清單。
