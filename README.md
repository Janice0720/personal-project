| [english-learning](english-learning/) | 英文課程錄音、逐字稿、單字與作業追蹤的管理系統 | 學習 |

## 慣例

- 各子專案自帶 `README.md`，細節以子專案文件為準
- 大型二進位檔（錄音檔、虛擬環境）不進 git，見 `.gitignore`
- Commit 訊息以繁體中文為主
