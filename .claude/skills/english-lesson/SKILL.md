# English Lesson 流程助理

專案位置：`english-learning/`（相對於 repo 根目錄）。
完整 SOP 見 `english-learning/README.md`；本 skill 定義 Claude Code 在每個階段該做什麼。

## 使用者只需記住四句話

| 使用者說 | 你做什麼 |
|---------|---------|
| 「幫我準備這週的課」 | 階段 P：建課前準備區（選擇性，有準備才有） |
| 「處理新課錄音」 | 階段 A：轉譯 + 產筆記 |
| 「幫我改作業」 | 階段 B：作業文法修正 |
| 「幫我收尾這堂課」 | 階段 C：單字 / 索引 / tracker |

## 檔案結構（課前、課後各自獨立一檔，同一個日期資料夾）

`notes/YYYY-MM-DD/` 內每堂課最多三個檔案：

| 檔案 | 性質 | 何時產生 |
|------|------|---------|
| `lesson-NN-<slug>-prep.md` | 課前準備（選擇性，有準備才有） | 上課前，階段 P |
| `lesson-NN-<slug>-notes.md` | 課堂筆記（依逐字稿填寫） | 上課後，階段 A |
| `lesson-NN-<slug>-homework.md` | 作業 | 上課後，階段 A |

> 課前想聊的主題和實際上課內容**可能不同**：prep 檔的 slug 依課前主題命名、**之後不改名**（它記錄的就是你準備了什麼）；notes/homework/逐字稿/錄音的 slug 則以課後逐字稿確認的實際主題為準。兩邊用連結互相對照。

---

## 階段 P｜課前準備（選擇性）

使用者說「幫我準備這週的課」「課前準備」時：

1. 判斷課堂編號（最後一堂 +1）與上課日期（跟使用者確認，通常是最近的週三）。
2. 建立 `notes/日期/lesson-NN-<slug>-prep.md`（slug 依課前主題命名），標題「課前準備 — Lesson NN：主題」，內容：
   - 本週想達成的目標
   - 分享草稿（可幫忙潤稿；初版收進 `<details>` 保留）
   - `## 課前預查單字` 表
3. 只建 prep 檔；notes/homework 檔由階段 A 的轉譯流程產生。
4. **預查單字表的標題必須是「課前預查單字」**（不可含「重點單字」字樣）——`extract_vocab.py` 只收 `*-notes.md` 中「重點單字」小節的表格，預查單字才不會誤入總表。

## 階段 A｜處理新課錄音

1. 執行 `bash scripts/lesson.sh new`（自動偵測 `recordings/` 根目錄的新錄音；轉譯 10–15 分鐘，放背景跑）。
   - 若使用者給了檔案路徑，改用 `bash scripts/lesson.sh <路徑>`。
   - `--topic/--slug` 依**實際上課主題**填（可先問使用者這堂課實際聊了什麼）；主題未知時先用 `--topic "待定" --slug tbd`，轉譯完成後讀逐字稿判斷主題，再把逐字稿/筆記/作業/錄音檔名中的 slug 與標題改為正確主題。
2. 轉譯完成後**親自讀逐字稿**，直接把 `notes/日期/lesson-NN-<slug>-notes.md` 填寫完整（不要留空模板、不需 API key 的 generate_notes.py）：
   - **同日期若有 prep 檔**：在筆記開頭加「🕐 課前準備」小節連結該檔（註明課前原訂主題），並在 prep 檔開頭補上課堂筆記的連結
   - 今日學習目標（2–3 條）
   - 課堂重點摘要（3–5 條；若有課前準備，順帶一句註明準備的主題實際有沒有聊到）
   - 重點單字／片語表（≥10 個，只取老師明確教授、示範或糾正的；例句用逐字稿原句）
   - 老師的關鍵糾正表（學生原句 → 老師建議；含老師對課前分享草稿的糾正；沒有就標註無）
   - 文法重點
3. 從逐字稿找出**老師指派的作業**，寫進 `-homework.md` 的「題目」與「繳交日期」，並在 `homework-tracker.md` 加一列（狀態 ⬜）。
4. 提醒使用者：「作業初稿請自己寫（不查字典），寫完說『幫我改作業』」。

## 階段 B｜幫我改作業

前提:使用者已在 `-homework.md` 的「我的初稿」寫好內容。若初稿是空的，請他先寫，**不要代寫初稿**（初稿保留原汁原味是這個學習法的核心）。

1. 讀該堂課的 homework 檔＋逐字稿（了解課堂教過什麼）。
2. 填「文法修正」表：原句 → 問題 → 建議（優先指出與課堂教學內容相關的錯誤）。
3. 填「修改後完整版」：整合修正、貼近使用者原意，不過度改寫。
4. 填「自我複習重點」：抽出 3–5 個值得記的句型與單字。
5. 更新 `homework-tracker.md` 狀態為 ✅ 已完成（待課堂討論）。

## 階段 C｜收尾這堂課

1. 若該堂有 `-prep.md` 檔：檢查其「課前預查單字」表，把課堂上**實際用到或老師糾正過**的單字搬進 notes 檔的「重點單字／片語」表（沒用到的留在 prep 檔，不進總表）。
2. 依序執行：

```bash
cd english-learning
python3 scripts/extract_vocab.py notes/日期/lesson-NN-<slug>-notes.md   # 單字入總表
bash scripts/update_index.sh                                            # 重建 README 課程索引
```

3. 再檢查 `homework-tracker.md` 狀態是否正確，最後詢問使用者是否 commit + push。

## 注意事項

- **錄音檔絕不進 git**（`.gitignore` 已排除）；`lesson.sh` 會自動歸檔並清理根目錄原始檔。
- 課堂編號 = 上課順序（依日期遞增）。若 `transcribe.py` 印出日期順序警告，先跟使用者確認再繼續。
- 逐字稿是 Whisper 自動產生，可能有辨識錯誤；筆記中引用例句時如明顯是辨識錯誤，修正拼寫但保留原意。
- `extract_vocab.py` 只掃 `*-notes.md`，且只收「重點單字」小節下的表格；prep 檔一律用 `-prep.md` 後綴、預查單字表標題不要含「重點單字」字樣。
- 筆記檔已填過內容時，**絕不用 `generate_notes.py --force` 重新產出**（會整檔覆寫）；一律手動增補。
- 課後複習節奏與 Anki 匯入見 `vocabulary/README.md`。
