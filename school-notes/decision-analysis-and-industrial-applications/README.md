# 決策分析與產業應用 (Decision Analysis and Industrial Applications)

課程筆記存放於此資料夾，建議以週次命名子檔案，例如 `week01-課程介紹.md`。

## 教學目標

在快速變動且充滿不確定性的產業環境中，決策品質往往是影響企業競爭力與組織績效的關鍵。本課程旨在介紹決策分析的重要觀念與核心方法，從不同角度探討決策的本質、流程及影響因素，並結合產業實務案例，說明決策分析在企業經營與管理上的應用。

## 教學內容

1. 決策分析緒論
2. 系統化決策分析
3. 確定性下的決策
4. 不確定性下的決策
