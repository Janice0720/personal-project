# 機器學習與決策 (Machine Learning and Decisions)

課程筆記存放於此資料夾，建議以週次命名子檔案，例如 `week01-課程介紹.md`。

## 教學目標

本課程通過一系列動手實作和解釋背後數學意涵的案例，介紹機器學習的概念和實際應用。

## 教學內容

本課程是為非 IT 專業學生設計的機器學習課程，課程的形式將是講座和課堂討論，課程內容將分為三個單元：

1. 監督學習－參數化模型和非參數化模型
2. 無監督學習
3. 參數調整和集成學習

學生在學習本課程之前假設已經具備基本的機率統計、矩陣代數和微積分等基礎。
