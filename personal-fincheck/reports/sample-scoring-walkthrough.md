## 1. 核心指標算法總覽

### 資料流

```
MyData PDF
    ↓ pdf_parser.py（正規式解析）
各類所得金額 + 扣繳稅額
    ↓ feature_engineering.py
所得佔比（ratio）＋ Shannon Entropy ＋ 稅務負擔率
    ↓
┌─────────────────────────────────────────────────────────┐
│  模組 A  Shannon Entropy → 所得多元化評分（0–100）         │
│  模組 B  扣繳稅率 vs 基準稅率 → 稅務效率評分（0–100）       │
│  模組 C  K-Means（K=5） → 財務人物分群                    │
│  模組 D  規則引擎 → 個人化理財建議（3 條）                  │
└─────────────────────────────────────────────────────────┘
```

### 模組 A：所得多元化評分

計算公式（`scoring.py → score_diversification`）：

```
H = -Σ (p_i × log₂(p_i))     # Shannon Entropy，p_i = 各類所得佔比
MAX_H = log₂(6) ≈ 2.585       # 六類完全均等時的最大熵值
多元化評分 = int( H / MAX_H × 100 )，範圍 0–100
```

- 分數越高 → 所得來源越分散 → 財務結構越穩健
- 6 類所得均等時達滿分 100 分

### 模組 B：稅務效率評分

計算公式（`scoring.py → score_tax_efficiency`）：

```
user_tax_rate     = 扣繳稅額 / 年度總所得
benchmark_rate    = 依總所得落入的分位組查表（low 5%、mid_low 8%、mid 11%、mid_high 14%、high 17%）
diff              = benchmark_rate − user_tax_rate
稅務效率評分 = int( 50 + (diff / benchmark_rate) × 50 )，範圍 0–100
```

- 個人稅率 **低於** 基準 → diff > 0 → 分數 > 50（節稅效果好）
- 個人稅率 **高於** 基準 → diff < 0 → 分數 < 50（有優化空間）

所得分位群組判斷（`scoring.py → classify_income_group`）：


| 群組       | 年度總所得範圍    | 基準扣繳稅率 |
| -------- | ---------- | ------ |
| low      | < 100 萬元   | 5%     |
| mid_low  | 100–130 萬元 | 8%     |
| mid      | 130–160 萬元 | 11%    |
| mid_high | 160–200 萬元 | 14%    |
| high     | ≥ 200 萬元   | 17%    |


### 模組 C：K-Means 財務人物分群

流程（`clustering.py → predict_persona`）：

```
特徵向量 = [salary_ratio, dividend_ratio, interest_ratio,
            rental_ratio, business_ratio, shannon_entropy]
    ↓ StandardScaler（訓練時統計量）標準化
    ↓ K-Means（K=5，random_state=42）計算歐式距離
    ↓ 指派至最近群中心
    ↓ cluster_id → 人物名稱（CLUSTER_NAMES 對照表）
```

#### 歐式距離計算過程

**Step 1：StandardScaler 標準化**

訓練資料（3,000 筆合成樣本）算出各特徵的均值與標準差，預測時對用戶特徵套用相同變換：

```
x_scaled = (x_raw − mean) / std
```


| 特徵              | 訓練集均值 (mean) | 訓練集標準差 (std) |
| --------------- | ------------ | ------------ |
| salary_ratio    | 0.1763       | 0.1242       |
| dividend_ratio  | 0.5676       | 0.1521       |
| interest_ratio  | 0.1483       | 0.1107       |
| rental_ratio    | 0.0182       | 0.0415       |
| business_ratio  | 0.0148       | 0.0363       |
| shannon_entropy | 1.5162       | 0.3198       |


**Step 2：歐式距離公式**

標準化後，對用戶向量 **u** 與每個群中心向量 **c_k** 計算歐式距離：

```
d(u, c_k) = √[ Σᵢ (uᵢ_scaled − cᵢ_k_scaled)² ]
```

距離最小的群即為分配結果。

**Step 3：具體計算範例（張小明 → 薪資投資型）**

原始特徵向量：

```
salary=0.3871, dividend=0.5806, interest=0.0323,
rental=0.0, business=0.0, entropy=1.1453
```

標準化後：

```
salary_scaled   = (0.3871 − 0.1763) / 0.1242 =  1.6971
dividend_scaled = (0.5806 − 0.5676) / 0.1521 =  0.0858
interest_scaled = (0.0323 − 0.1483) / 0.1107 = −1.0484
rental_scaled   = (0.0000 − 0.0182) / 0.0415 = −0.4385
business_scaled = (0.0000 − 0.0148) / 0.0363 = −0.4077
entropy_scaled  = (1.1453 − 1.5162) / 0.3198 = −1.1597
```

對薪資投資型群中心（cluster 0）計算歐式距離：


| 特徵       | 用戶值 (u) | 群中心 (c₀) | 差值 (u−c₀) | 差值²        |
| -------- | ------- | -------- | --------- | ---------- |
| salary   | 1.6971  | 1.1416   | 0.5555    | 0.3086     |
| dividend | 0.0858  | −0.5736  | 0.6594    | 0.4348     |
| interest | −1.0484 | −0.4056  | −0.6428   | 0.4132     |
| rental   | −0.4385 | −0.2302  | −0.2083   | 0.0434     |
| business | −0.4077 | −0.1665  | −0.2412   | 0.0582     |
| entropy  | −1.1597 | 0.3673   | −1.5270   | 2.3317     |
| **合計**   |         |          |           | **3.5899** |


```
d(張小明, cluster 0) = √3.5899 = 1.895  ✅
```

## 2. 01 張小明（薪資投資型）

### 原始資料（PDF 解析）


| 所得類別   | 扣繳單位       | 給付金額          | 扣繳稅額       |
| ------ | ---------- | ------------- | ---------- |
| 薪資     | 台灣積體電路製造   | 600,000       | 18,000     |
| 股利/營利  | 元大台灣50 ETF | 900,000       | 0          |
| 利息     | 台灣銀行       | 50,000        | 5,000      |
| **合計** |            | **1,550,000** | **23,000** |


### 所得佔比


| 類別    | 金額      | 佔比        |
| ----- | ------- | --------- |
| 薪資    | 600,000 | **38.7%** |
| 股利/營利 | 900,000 | **58.1%** |
| 利息    | 50,000  | **3.2%**  |


### 模組 A：所得多元化評分 → **44 分**

```
p = [0.3871, 0.5806, 0.0323, 0, 0, 0]

H = -(0.3871×log₂(0.3871) + 0.5806×log₂(0.5806) + 0.0323×log₂(0.0323))
  = -(0.3871×(-1.3691) + 0.5806×(-0.7849) + 0.0323×(-4.9534))
  = -(-0.5301 + (-0.4558) + (-0.1600))
  = 1.1453

多元化評分 = int(1.1453 / 2.585 × 100) = int(44.3) = 44 分
```

解讀：僅三類所得有值，股利佔 58% 偏集中，評分中等。

### 模組 B：稅務效率評分 → **93 分**

```
user_tax_rate     = 23,000 / 1,550,000 = 1.48%
所得群組          = mid（總所得 155 萬，介於 130–160 萬）
benchmark_rate    = 11%

diff  = 0.11 − 0.0148 = 0.0952
score = 50 + (0.0952 / 0.11) × 50 = 50 + 43.3 = 93 分
```

解讀：ETF 股利扣繳為 0，大幅壓低個人稅率（1.48%），遠低於基準的 11%，稅務效率極高。

### 模組 C：K-Means 分群 → **薪資投資型**


| 群     | 人物類型      | 歐式距離           |
| ----- | --------- | -------------- |
| **0** | **薪資投資型** | **1.895** ← 最近 |
| 3     | 股利集中型     | 2.552          |
| 4     | 保守固定型     | 3.657          |
| 2     | 多元資產型     | 4.786          |
| 1     | 自雇型       | 5.021          |


薪資 38.7% + 股利 58.1% 最接近薪資投資型群心（薪 31.8% + 股 48.0%）。

### 模組 D：個人化建議


| 觸發條件                 | 建議                             |
| -------------------- | ------------------------------ |
| 多元化 44 分（35–65 中等區間） | 可增加穩定固定收益資產（投資等級債券），降低整體波動     |
| 稅務效率 93 分（≥ 70 良好）   | 持續保持規劃，可評估股利所得分離課稅（28%）vs 合併計稅 |
| 薪資投資型專屬              | 優先建立 6 個月緊急預備金後，再提高投資配置比例      |

| 利息     | 郵局儲蓄存款 | 70,000      | 7,000      |

### 所得佔比


| 類別    | 金額      | 佔比        |
| ----- | ------- | --------- |

| 股利/營利 | 400,000 | **51.3%** |

### 模組 A：所得多元化評分 → **56 分**

```
p = [0.1923, 0.5128, 0.2949, 0, 0, 0]

H = -(0.1923×log₂(0.1923) + 0.5128×log₂(0.5128) + 0.2949×log₂(0.2949))
  = -(0.1923×(-2.3782) + 0.5128×(-0.9641) + 0.2949×(-1.7626))
  = -(-0.4573 + (-0.4946) + (-0.5199))
  = 1.4718 ≈ 1.471

多元化評分 = int(1.471 / 2.585 × 100) = int(56.9) = 56 分
```

解讀：三類所得分佈相對均衡，評分 56 分，介於「中等」區間上緣。

### 模組 B：稅務效率評分 → **64 分**

```
user_tax_rate     = 27,500 / 780,000 = 3.53%
所得群組          = low（總所得 78 萬 < 100 萬）
benchmark_rate    = 5%

diff  = 0.05 − 0.0353 = 0.0147
```
