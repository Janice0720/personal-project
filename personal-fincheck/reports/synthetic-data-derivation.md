## 4. 生成算法說明

每個合成個體的產生共三步驟（程式碼：`generate_synthetic_data.py`）：

### 步驟一：生成年度總收入

使用 **log-normal 分佈** 模擬真實所得的右偏特性：

```python
total_income = int(np.random.lognormal(
    mean  = log(base_income),   # 以各群薪資收入均值為中心（自然對數）
    sigma = 0.4                 # 控制個體間差異幅度
))
```

log-normal 分佈的選擇理由：
- 真實所得分佈呈右偏（少數高所得者拉高均值）
- sigma = 0.4 使各群最大值約為均值的 3–5 倍，符合台灣所得分散程度

### 步驟二：生成各類所得比例

使用 **Dirichlet 分佈** 在各群基準比例附近加入個體隨機差異：

```python
proportions  = [salary%, dividend%, interest%, rental%, business%, other%] / 100
noisy_prop   = np.random.dirichlet(proportions × 10)
# concentration = 比例 × 10，值越大 → 個體差異越小，越貼近群基準
```

各類所得金額：
```python
income_per_category = int(total_income × noisy_prop[i])
```

### 步驟三：生成扣繳稅額

```python
withholding_tax = int(total_income × base_tax_rate × random.uniform(0.8, 1.2))
# ±20% 隨機擾動，模擬個體實際扣繳與基準的差異
```

## 6. 合成資料用途與限制

### 用途

合成資料**僅用於 K-Means 分群模型的訓練**（`train_model.py`）。K-Means 使用的 6 個特徵均為**所得佔比與 Shannon Entropy**，不使用絕對金額，因此收入規模的高低不影響分群結果。

```
K-Means 特徵：
  salary_ratio, dividend_ratio, interest_ratio,
  rental_ratio, business_ratio, shannon_entropy
（不含 total_income、withholding_tax、tax_burden_rate）
```

### 限制

| 限制項目 | 說明 |
|---|---|
| **不代表台灣人口全貌** | 僅涵蓋 111 年度有申報綜所稅的 663 萬戶，不含無申報所得者 |
| **所得結構高度集中股利** | 原始統計反映台灣申報戶股利佔比偏高（全體均值 59%），合成資料繼承此特性，導致 K-Means 五群的股利佔比均在 47–72%，不適用於非股利型所得結構 |
| **收入規模偏低** | 以薪資收入均值（7.4 萬–19.8 萬/年）為基準，合成個體年收入普遍低於 100 萬，不涵蓋高資產族群（股利千萬等級）的特徵分佈 |
| **非真實個人資料** | 為模擬資料，不可用於任何統計推論或政策分析 |
