# FinCheck 操作手冊

FinCheck 是一套基於台灣財政部官方統計資料與 MyData 個人所得情境設計的財務健檢 AI 系統，透過 K-Means 分群與多維度評分模型，為使用者產出個人化財務健檢報告。

## 1. 初始化流程

### 步驟一：進入專案目錄

```bash
cd personal-fincheck
```

### 步驟二：確認模型檔案已存在

```bash
ls models/kmeans_model.pkl
```

若 `models/kmeans_model.pkl` **不存在**，請參考第 [5 節](#5-腳本維護與模型重訓)重新建立。

## 3. 使用介面操作說明

儀表板提供兩種輸入方式，切換上方分頁即可選擇。

### 方式一：上傳 MyData PDF（推薦）

> 最完整、最準確的分析方式，無需手動輸入任何數字。

**如何取得個人所得資料 PDF？**

```
MyData 平台（mydata.nat.gov.tw）
  → 登入（自然人憑證 或 行動身分識別）
  → 選擇「財政部財政資訊中心」→「個人所得資料」
  → 選擇申報年度 → 下載 PDF
```

**上傳與解析流程：**

1. 點選「📄 上傳 MyData PDF（推薦）」分頁
2. 點擊「Browse files」選取從 MyData 下載的 PDF 檔案
3. 系統自動解析，成功後顯示：
  - 納稅義務人姓名、申報年度
  - 各類所得金額摘要
  - 合計驗證結果（✅ 表示解析金額與 PDF 合計吻合）
4. 展開「📋 所得明細」可查看每筆記錄（扣繳單位、金額、扣繳稅額）
5. 分析結果自動呈現於下方

**注意事項：**

- 僅支援財政部「年度綜合所得稅各類所得資料清單」格式的 PDF
- 若 PDF 帶有浮水印（如「財政部臺北國稅局中正分局」等文字）屬正常情況，系統已內建自動過濾

---

### 方式二：手動輸入

> 沒有 MyData PDF 時，可直接輸入各類所得金額。

1. 點選「✏️ 手動輸入」分頁
2. 在各欄位填入**年度所得金額（元）**：


| 欄位      | 說明              | 舉例      |
| ------- | --------------- | ------- |
| 薪資所得    | 公司每月薪資、年終獎金合計   | 600,000 |
| 股利/營利所得 | ETF、股票股利及營利事業所得 | 200,000 |
| 利息所得    | 定存、債券、活存利息      | 50,000  |
| 租賃所得    | 房屋出租收入          | 0       |
| 執行業務所得  | 自由業、顧問費、稿費      | 0       |
| 其他所得    | 財產交易、競技、其他雜項    | 0       |
| 扣繳稅額合計  | 所有來源的扣繳稅額總和     | 60,000  |


1. 點擊「🔍 開始健檢」按鈕，結果即顯示於下方

## 4. 健檢結果解讀指南

分析完成後，頁面依序顯示以下區塊：

### 4.1 核心指標（四格看板）


| 指標          | 說明                                     |
| ----------- | -------------------------------------- |
| **財務人物類型**  | K-Means 分群結果，共五種類型（見下表）                |
| **所得多元化評分** | Shannon Entropy 換算，0–100 分，越高代表所得來源越分散 |
| **稅務效率評分**  | 與同所得層基準稅率比較，0–100 分，越高代表稅務負擔相對較低       |
| **年度總所得**   | 所有所得類別的加總金額（元）                         |


**五種財務人物類型說明：**


| 類型    | 典型特徵               | 解讀             |
| ----- | ------------------ | -------------- |
| 薪資投資型 | 薪資約 32%、股利約 48%    | 上班族投資人，工作與投資並重 |
| 自雇型   | 執行業務所得約 14.5%，搭配股利 | 自雇或兼業的複合所得結構   |
| 股利集中型 | 股利佔比 > 70%         | 高度依賴股票/ETF 配息  |
| 保守固定型 | 利息所得佔比 > 25%       | 偏好定存、債券等固定收益   |
| 多元資產型 | 股利、租賃、利息三類並重       | 資產最為分散的類型      |


### 4.2 圖表區塊

- **所得來源結構（圓餅圖）**：各類所得佔比視覺化，零值類別自動隱藏
- **財務健檢雷達圖**：所得多元化、稅務效率、整體健康度三維度比較

### 4.3 稅務效率詳細說明（可展開）

顯示你的扣繳稅率、同所得層基準稅率、與基準的差距（正數代表稅率偏高、負數代表相對有效率）。

### 4.4 個人化理財建議

系統根據人物類型與評分，輸出 3 條具體建議，分別針對：

1. 所得多元化方向
2. 稅務規劃方向
3. 人物類型專屬策略

### 4.5 AI 分群說明（可展開）

說明 K-Means 模型建構方式、訓練資料來源，以及 K=5 的三項評估指標數值（Silhouette Score、Davies-Bouldin、Calinski-Harabasz）。

## 5. 腳本維護與模型重訓

若需從頭建立整套系統，按以下順序執行：

```
scripts/
├── generate_synthetic_data.py  # 步驟 1：生成合成訓練資料（3,000 筆）
├── train_model.py              # 步驟 2：K-Means 訓練並儲存模型
├── generate_sample_pdfs.py     # 步驟 3：（選用）生成五種人物的範本 PDF
├── generate_charts.py          # 步驟 4：（選用）產出 Elbow / 分群圖表
```

**執行指令（從專案根目錄）：**

```bash
python3 scripts/generate_synthetic_data.py   # 產出 data/processed/synthetic_data.csv
python3 scripts/train_model.py               # 產出 models/kmeans_model.pkl
```

**測試腳本：**

```bash
python3 scripts/test_scoring.py   # 驗證評分模組
python3 scripts/test_mydata.py    # 驗證 PDF 解析（使用 data/sample_pdfs/ 中的範本）
```

**核心腳本說明：**


| 腳本                       | 用途                             |
| ------------------------ | ------------------------------ |
| `feature_engineering.py` | 計算各類所得佔比、Shannon Entropy、稅務負擔率 |
| `clustering.py`          | K-Means 模型訓練、評估、預測財務人物類型       |
| `scoring.py`             | 多元化評分、稅務效率評分、個人化建議生成           |
| `pdf_parser.py`          | 解析財政部 MyData PDF，提取所得記錄        |

## 6. 常見問題排除

### Q1：啟動 Streamlit 後瀏覽器開啟空白頁？

確認 terminal 中已看到 `Local URL: http://localhost:8501`，手動在瀏覽器輸入此網址。

### Q2：上傳 PDF 後顯示「解析失敗」？

- 確認上傳的是財政部「年度綜合所得稅各類所得資料清單」PDF，而非其他格式（如報稅系統產出的申報書）
- 系統支援財政部標準格式，包含浮水印文字

### Q3：出現 `InconsistentVersionWarning` 警告？

代表儲存的模型檔（`.pkl`）是舊版 scikit-learn 訓練的，但目前環境版本較新。請重新訓練模型：

```bash
python3 scripts/train_model.py
```

### Q4：合計驗證顯示「⚠️ 有差異」？

系統允許 ±1 元的千分位捨入誤差。若差異超過此範圍，可能是該 PDF 包含非標準格式的欄位，分析仍可繼續，但建議與手動輸入結果交叉比對。

### Q5：找不到 `models/kmeans_model.pkl`？

```bash
python3 scripts/generate_synthetic_data.py
python3 scripts/train_model.py
```

依序執行以上兩個腳本即可重新生成模型檔案。
