## 1. 專案概述

**題目背景**：AI × 資料科學 × 金融分析期中報告

**系統定位**：使用者透過 MyData 平台（mydata.nat.gov.tw）授權下載個人所得資料後，AI 系統自動分析所得結構，產出個人化財務健檢報告。

**核心問題**：一般民眾難以客觀評估自己的財務健康狀態——薪資結構是否穩健？所得多元化程度如何？與同齡台灣人相比處於什麼分位？

**報告三面向對應**：

| 面向 | 對應做法 |
|---|---|
| A 資料工程 | 下載財政部 data.gov.tw 公開資料 + 基於統計分佈生成合成個體資料 |
| B AI/ML 建模 | K-Means 財務人物分群 + 多維度評分計算（Shannon Entropy、稅務效率） |
| C 洞察產出 | Streamlit 互動儀表板 + 個人化健檢報告文字 |

## 2. 系統架構

```
【訓練階段】
財政部公開統計資料（data/raw/）
        ↓
依統計分佈生成合成個體資料（3,000 筆）
        ↓
K-Means 訓練 → 建立財務人物分群模型
        ↓
儲存模型（notebooks/models/kmeans_model.pkl）

【推論階段（MyData 情境）】
使用者透過 MyData 下載個人所得資料
        ↓
輸入個人所得結構（薪資、股利、利息、租賃...）
        ↓
套用已訓練模型 → 判斷財務人物類型
        ↓
產出健檢報告（所得多元化評分、稅務效率評分、分群結果、AI 建議）
```

## 5. 分析模組說明

### 模組 A：所得多元化評分

使用 **Shannon Entropy（夏農熵）** 計算所得來源的多元程度：

- 所得僅來自薪資 → 熵值低 → 評分較低（穩定但單一）
- 薪資 + 股利 + 利息並重 → 熵值高 → 評分較高（多元穩健）

### 模組 B：稅務效率評分

計算公式：`稅務負擔率 = 扣繳稅額 / 給付總額`

對照同分位平均稅務負擔率，判斷是否有節稅規劃空間。

### 模組 C：K-Means 財務人物分群

預計分為 4 種財務人物：

| 類型 | 特徵 | 理財建議方向 |
|---|---|---|
| 薪資型 | 薪資佔比 > 80% | 建立被動收入、開始投資 |
| 投資型 | 股利＋利息佔比 > 50% | 資產配置多元化 |
| 自雇型 | 執行業務所得佔比高 | 退休規劃、保障型保險 |
| 混合型 | 各類所得相對均衡 | 持續優化稅務效率 |

### 模組 D：AI 個人化建議

根據健檢分數產出 2～3 條個人化建議文字，優先使用規則引擎；進階版可選接 OpenAI API 生成更自然的建議語句。
