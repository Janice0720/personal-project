# career-development

集中管理下一份工作求職準備：職涯方向、時間軸、技能盤點與學習計畫。

---

## 目標

- 釐清下一份工作的**方向與優先條件**（Microsoft 中期、Google 長期）
- 系統化追蹤**技能現況與缺口**，對照學習計畫執行
- 以時間軸管理**2026.05–2027.07 應徵準備期**的里程碑

## 方法

- 以 Markdown 文件記錄規劃與技能盤點（本資料夾）
- 定期（建議每週）回顧 `plans/career-roadmap.md`，更新狀態與下一步
- 技能有變動時更新 `skills/skills-inventory.md`

## 資料夾結構

```
career-development/
├── README.md
├── plans/                    ← 職涯方向、求職策略、時程
└── skills/                   ← 技能盤點、缺口分析、學習計畫
```

> 履歷、作品集、應徵紀錄等資料夾待需要時再建立。

## 快速開始

1. 查閱 [`plans/career-roadmap.md`](plans/career-roadmap.md) 確認時間軸與目標職缺
2. 對照 [`skills/skills-inventory.md`](skills/skills-inventory.md) 的缺口表，安排本週學習重點
3. 每週在 roadmap 底部填寫週回顧

## 結論

> 2026-05-19 完成職涯 roadmap 與技能盤點初版；目前處於技能補強期（2026.05–2027.07）。
