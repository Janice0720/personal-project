## 三、LeetCode 練習建議

### 3.1 練習目標

| 類別 | 目標 | 說明 |
|---|---|---|
| SQL | 主力練習項目 | 對 Product Analyst / Data Analyst / Business Analyst 類職缺最直接相關 |
| Python Easy | 輔助練習 | 目的不是走 SWE，而是補 Python 語法、資料結構與解題邏輯 |
| Python pandas / 資料分析 | 作品集導向 | LeetCode 可練基礎，但仍需用真實分析 project 補足資料清理與商業洞察 |
| 面試思維 | 訓練解題表達 | 每題練習後要能說明：問題、解法、SQL 邏輯、edge case、可優化處 |

### 3.2 LeetCode SQL 練習重點

| 主題 | 建議練習內容 |
|---|---|
| 基礎查詢 | SELECT、WHERE、GROUP BY、ORDER BY、HAVING |
| Join | INNER JOIN、LEFT JOIN、多表 join |
| Aggregation | COUNT、SUM、AVG、MAX、MIN、distinct users |
| Window Function | ROW_NUMBER、RANK、DENSE_RANK、LAG、LEAD、SUM OVER |
| Retention / Cohort | 次日留存、連續登入、首次交易、回訪用戶 |
| Funnel | 每步轉換、drop-off、完成率 |
| Ranking | Top N、每組最高、每類排名 |
| Rolling Metrics | 7-day average、累積值、moving window |
| Date Handling | 日期差、月份彙總、週期計算 |
| Product Metrics | DAU、MAU、conversion、churn、active users |

### 3.3 每週 LeetCode 節奏

| 階段 | 時間 | 每週題數 | 題型 |
|---|---|---:|---|
| 基礎期 | 2026.05–2026.07 | SQL 3 題 + Python 1 題 | Easy 為主，建立語法與查詢手感 |
| 強化期 | 2026.08–2026.12 | SQL 4–5 題 + Python 1–2 題 | SQL Easy / Medium，開始練 window function 與留存題 |
| 面試期 | 2027.01–2027.05 | SQL 5–7 題 + Python 2 題 | Medium 為主，加入限時與口述解題 |
| 衝刺期 | 2027.06–2027.07 | SQL 7 題 + Python 2 題 | 模擬面試，整理錯題本與常見 pattern |
