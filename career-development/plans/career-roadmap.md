## 3. 求職策略

### 核心策略

```text
1. 保留原有優勢：Fintech domain + Product + Data + BI + Cross-functional
2. 補齊關鍵缺口：Python + Azure + A/B Testing + English + Program Management
3. 建立作品集：Product Analytics + A/B Testing + Data Pipeline + Azure Data Platform
4. 2027 年進入 Microsoft 或大型科技 / Fintech 公司
5. 第二階段累積 scale、global collaboration、cloud/data solution、product ownership
6. 3–5 年內挑戰 Google
```

- **主打賣點**：Fintech Product & Data Analyst — GA4 / BigQuery / Power BI / SQL / 使用者行為分析 / CRM 分群 / 跨部門產品推動
