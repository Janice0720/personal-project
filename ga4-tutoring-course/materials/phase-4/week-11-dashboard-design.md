## 3. 核心概念 A：互動控制元件（Interactive Controls）

### 3.1 為什麼報表需要互動？

想像你在電影院的售票機前。如果螢幕只能顯示「今天所有場次」而不能篩選——你得自己從一百多場裡找到想看的電影，體驗很差。但如果有下拉選單讓你選「電影類型」、有日期選擇讓你選「哪一天」，三秒就能找到答案。

**儀表板也是一樣。** 沒有互動控制的報表是一張「死圖」，所有人看到同樣的數據。加上控制項後，同一份報表能滿足不同角色的需求——網站經營者切換日期看趨勢，社群小編篩選 Instagram 流量，行動優化人員只看手機數據。

### 3.2 三大控制項類型

| 控制項 | 功能 | MovieTribe 應用 |
|-------|------|----------------|
| 時間範圍控制項（Date Range Control） | 讓使用者選擇查看的時間區間，建議預設「最近 28 天」 | 比較本週 vs 上週流量變化 |
| 下拉式篩選器（Drop-down Filter） | 依維度篩選數據，支援單選或多選 | 篩選裝置類型、來源管道、國家 |
| 導覽按鈕（Navigation Link） | 在多頁面報表間跳轉，或連結到外部頁面 | 頂部導覽列連結各分析頁面 |

## 4. 實作步驟 A：為報表加入互動控制

### 4.1 加入日期選擇器與篩選器

1. 開啟 Week 10 的報表 → 點擊「**編輯**」進入編輯模式
2. 上方工具列 →「**新增控制項**」→「**日期範圍控制項**」，拖曳到報表標題右側
3. 在右側屬性面板設定預設日期為「最近 28 天」，比較日期為「上一期」
4. 再次「新增控制項」→「**下拉式清單**」，控制項欄位選「**裝置類別**」
5. 同樣步驟新增第二個下拉式清單，欄位改選「**工作階段預設管道群組**」，勾選「**允許多選**」

```
┌─────────────────────────────────────────────────────────┐
│  MovieTribe 數據儀表板          [日期選擇器] [裝置▼] [來源▼] │
├─────────────────────────────────────────────────────────┤
│  （以下圖表區域會隨篩選器連動更新）                           │
└─────────────────────────────────────────────────────────┘
```

6. 切換到「**檢視**」模式確認所有控制項可正常運作

### 4.2 控制項的適用範圍

預設情況下，控制項會影響同一頁上所有使用相同資料來源的圖表。若需要讓某個控制項只影響特定圖表：按住 Shift 同時選取控制項與目標圖表 → 右鍵 →「**建立群組**」，群組內的控制項只影響群組內的圖表。

## 5. 核心概念 B：計算欄位（Calculated Fields）

### 5.1 什麼是計算欄位？

GA4 提供的原始指標（如工作階段數、使用者數）像超市買回來的食材——雞蛋、麵粉、糖。直接用沒問題，但如果組合加工就能做出蛋糕。**計算欄位就是你的食譜**，用既有指標透過公式產生新的自訂指標。

計算欄位分兩個層級：**資料來源層級**（所有報表共用，適合通用指標如轉換率）和**圖表層級**（僅限單一圖表，適合特殊計算）。不確定時，先建在資料來源層級比較方便。

### 5.2 常用計算公式

| 自訂指標名稱 | 公式 | 用途 |
|-------------|------|------|
| 每工作階段頁面瀏覽數 | `screenPageViews / sessions` | 衡量每次造訪的瀏覽深度 |
| 互動率（%） | `engagedSessions / sessions * 100` | 有效互動的比例 |
| 每位使用者工作階段數 | `sessions / totalUsers` | 使用者回訪頻率 |

> Looker Studio 的公式使用 **API 名稱**（如 `screenPageViews`），非 GA4 介面的中文名稱。建立公式時可在搜尋框中輸入中文找到對應欄位。

### 5.3 CASE WHEN 條件邏輯

CASE WHEN 類似 Excel 的 IF 函數，但能處理多個條件分支，是建立自訂維度的核心工具。

```sql
CASE
  WHEN 條件1 THEN 結果1
  WHEN 條件2 THEN 結果2
  ELSE 預設結果
END
```

用電影票務類比——`CASE WHEN 年齡 < 12 THEN '兒童票' WHEN 年齡 < 65 THEN '全票' ELSE '敬老票' END`。

**常用搭配函數：**

| 函數 | 功能 | 範例 |
|------|------|------|
| `CONTAINS_TEXT(欄位, "關鍵字")` | 判斷文字是否包含關鍵字 | 判斷頁面路徑是否含 `/movie/` |
| `REGEXP_MATCH(欄位, "正則式")` | 正規表達式比對 | 比對複雜網址模式 |
| `IF(條件, 真值, 假值)` | 簡易二分法判斷 | 是否互動（是/否） |

## 6. 實作步驟 B：建立自訂計算欄位

**建立「每工作階段頁面瀏覽數」：**

1. 編輯模式 → 上方「**資源**」→「**管理新增的資料來源**」→ GA4 資料來源旁「**編輯**」
2. 點擊「**新增欄位**」→ 欄位名稱輸入 `每工作階段頁面瀏覽數`
3. 公式輸入 `screenPageViews / sessions` → 儲存 → 完成
4. 回到報表，在任何圖表中即可使用這個新指標

**建立「流量來源分類」（CASE WHEN 實作）：**

同樣在資料來源中新增欄位，公式如下：

```sql
CASE
  WHEN sessionDefaultChannelGroup IN ("Organic Search", "Paid Search")
    THEN "搜尋流量"
  WHEN sessionDefaultChannelGroup IN ("Organic Social", "Paid Social")
    THEN "社群流量"
  WHEN sessionDefaultChannelGroup = "Direct"
    THEN "直接流量"
  ELSE "其他流量"
END
```

這個計算維度可用在圓餅圖中，把十幾種管道群組簡化為四大類，一眼看懂流量結構。

## 7. 核心概念 C：視覺設計與品牌感

### 7.1 「少即是多」原則

儀表板最常見的錯誤是「資訊過載」——把能放的圖表全塞進一頁，像電影海報把劇情大綱、演員介紹、幕後花絮全印上去。

| 原則 | 說明 |
|------|------|
| 一頁一主題 | 每個頁面只回答一個核心問題 |
| 重要的放最大 | KPI 計分卡佔最醒目位置，單頁建議 4-6 個 |
| 留白（Whitespace）是你的朋友 | 適當空白讓內容更好閱讀，圖表單頁 3-4 張為宜 |

### 7.2 配色方案與版面布局

**品牌色彩融入：** 先到 MovieTribe 網站擷取品牌色碼，再搭配以下色彩角色建立方案：

| 色彩角色 | 用途 | MovieTribe 建議 |
|---------|------|----------------|
| 主色（Primary） | KPI 標題、重點圖表 | 品牌主色 |
| 背景色 | 報表底色 | #1A1A2E 深藍（電影院質感）或 #F5F5F5 淺灰 |
| 強調色（Accent） | 特別注意的數字 | #F5C518 金黃（IMDb 風格） |
| 警示色 | 未達標數值 | #E74C3C 紅色 |

在 Looker Studio 中，點擊「**主題和版面配置**」可一次設定整份報表的配色、字型與圖表顏色。

**版面布局結構（由上到下 = 由總到細）：**

```
┌─────────────────────────────────────────────────────────┐
│  HEADER：Logo + 報表標題 + 日期選擇器 + 篩選器            │
├─────────────────────────────────────────────────────────┤
│  KPI 區：計分卡橫排（使用者數 / 工作階段 / 互動率 / 轉換） │
├──────────────────────┬──────────────────────────────────┤
│  趨勢圖（折線圖）     │  組成分析（圓餅圖/長條圖）         │
├──────────────────────┴──────────────────────────────────┤
│  明細表格（Top 10 頁面或維度交叉分析）                      │
├─────────────────────────────────────────────────────────┤
│  FOOTER：資料更新時間 + 報表製作者                         │
└─────────────────────────────────────────────────────────┘
```

### 7.3 條件格式（Conditional Formatting）

條件格式讓數字自動「變色說話」——轉換率低於目標自動標紅，超過目標標綠。

**設定方式：** 選取計分卡或表格 → 右側「樣式」→「條件格式」→ 新增規則：

| 條件 | 顏色 | 語意 |
|------|------|------|
| 值 < 3% | #E74C3C 紅色 | 未達標，需要關注 |
| 值 >= 3% 且 < 5% | #F39C12 橘色 | 及格邊緣 |
| 值 >= 5% | #27AE60 綠色 | 達標 |

> 條件格式是一種「預警系統」——其他團隊成員打開報表就能立刻知道哪裡有問題，不需要你一一解釋。

## 8. 多頁面報表與導覽設計

一份好的儀表板像一部電影——有清楚的章節結構。建議 MovieTribe 規劃 3-4 個頁面：

| 頁面 | 名稱 | 核心問題 | 主要圖表 |
|:----:|------|---------|---------|
| P1 | 總覽 | 網站整體表現？ | KPI 計分卡、每日趨勢折線圖、流量來源圓餅圖 |
| P2 | 流量與來源 | 使用者從哪來？ | 管道分布長條圖、來源明細表、裝置占比 |
| P3 | 內容表現 | 哪些內容最受歡迎？ | Top 10 頁面表格、互動時間分布 |
| P4 | 轉換追蹤 | 目標達成率？ | 轉換趨勢折線圖、轉換率明細表（含條件格式） |

**導覽列建立方式：** 在報表頂部插入矩形色塊作為導覽背景，在上方放置文字框寫上每頁名稱，選取文字框 → 右側「連結」→ 選擇對應頁面。將當前頁面的按鈕設為不同顏色作為位置提示。

## 9. 分享與協作

### 權限設定

| 權限等級 | 能做的事 | 適合對象 |
|---------|---------|---------|
| 檢視者（Viewer） | 瀏覽、使用篩選器、下載 PDF | 主管、團隊成員 |
| 編輯者（Editor） | 檢視者功能 + 修改報表設計 | 共同維護報表的夥伴 |
| 擁有者（Owner） | 所有功能 + 刪除、轉移擁有權 | 報表建立者 |

### 自動排程寄送（Scheduled Delivery）

讓報表「主動找人」——在檢視模式下，點擊「分享」→「**排定電子郵件傳送時間**」：

1. 設定收件人（可多位）
2. 選擇頻率：每天（活動期間）、每週（例行週報，建議週一 9:00）、每月（月度回顧）
3. 選擇寄送頁面與格式（PDF 或 CSV）

> 排程寄送的 PDF 是靜態快照，會以設定當下的篩選器狀態為準。建議先將篩選器歸位到預設值再設定排程。

## 10. MovieTribe 品牌儀表板設計

### 電影主題視覺風格

MovieTribe 是電影主題社群，儀表板應讓人一看就聯想到「電影」。建議採用電影院暗色調：

| 元素 | 建議 |
|------|------|
| 背景色 | #1A1A2E 深海軍藍（放映廳氛圍） |
| 主色 | #E94560 經典紅（電影院座椅、紅毯） |
| 強調色 | #F5C518 IMDb 金黃（KPI 數字亮眼） |
| Logo | 放在報表左上角，搭配「MovieTribe 數據總覽」標題 |
| 頁尾 | 「Powered by MovieTribe」+ 資料更新時間 |

### KPI 版面設計

以 4 張計分卡橫排呈現核心指標：

```
┌───────────┬───────────┬───────────┬───────────┐
│  活躍      │  工作      │  平均互動  │  註冊      │
│  使用者數  │  階段數    │  時間      │  轉換率    │
│  1,250    │  2,800    │  2:15     │  3.2%     │
│  ▲ 12%    │  ▲ 8%     │  ▼ -5%    │  ▲ 0.5%   │
└───────────┴───────────┴───────────┴───────────┘
```

| KPI | 為什麼重要 |
|-----|----------|
| 活躍使用者數 | 核心價值指標——有多少人在使用 MovieTribe |
| 工作階段數 | 網站總造訪量 |
| 平均互動時間 | 電影社群的內容是否吸引人停留 |
| 註冊轉換率（計算欄位） | 最終商業目標 |

計分卡的比較日期設為「上一期」，正值顯示綠色、負值紅色，讓變化一目了然。

## 12. FAQ — 常見問題

**Q1：篩選器加了之後，某些圖表沒有跟著變？**

確認所有圖表都連接到同一個 GA4 資料來源。若確實相同，檢查圖表是否被放在不同「群組」中，或在圖表屬性中手動設了篩選器覆寫了控制項。

**Q2：計算欄位的公式顯示「錯誤」？**

三步排查：(1) 欄位名稱是否用了 API 名稱而非中文；(2) 除法分母是否可能為零——用 `IF(sessions = 0, 0, screenPageViews / sessions)` 避免；(3) CASE WHEN 是否以 `END` 結尾。

**Q3：深色背景的報表文字看不清楚？**

需手動將所有文字、座標軸標籤、表格標題改為白色或淺灰。建議先用淺色背景完成設計，最後再切換深色並逐一調整。

**Q4：排程寄送的 PDF 跟線上版不一樣？**

PDF 是靜態截圖，不含互動功能。會使用排程設定當下的篩選器狀態。建議先將篩選器歸位到預設值再設定排程。

**Q5：計算欄位建在「資料來源層級」還是「圖表層級」？**

會在多張圖表或多份報表中重複使用的（如轉換率），建在資料來源層級。只是某張圖表的特殊需求，建在圖表層級即可。

**Q6：報表可以嵌入到 MovieTribe 網站上嗎？**

可以，在分享選單中「取得嵌入程式碼」會產生 iframe。但嵌入的報表是公開的，若只是內部使用，直接分享連結更適合。
