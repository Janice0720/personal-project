## 3. 核心概念：為什麼需要 Looker Studio？

### 3.1 GA4 探索報表的瓶頸

在 Week 7-9，我們已經能在 GA4 探索報表中做出各種進階分析。但你有沒有遇過以下情境？

| 瓶頸 | 具體描述 |
|------|---------|
| 分享困難 | 想給老闆看報表，但對方沒有 GA4 帳號或不知道怎麼操作 |
| 介面太複雜 | 非技術人員打開 GA4 後台，看到一堆維度、指標、探索技巧就頭暈 |
| 不能客製版面 | GA4 的報表格式固定，無法自由擺放圖表、加上品牌色彩 |
| 無法跨數據源 | 想把 GA4 數據和 Google Ads、Search Console 放在同一頁比較？GA4 做不到 |

**一句話總結**：GA4 是「分析師的工作台」，Looker Studio 是「給所有人看的展示板」。

### 3.2 什麼是 Looker Studio？

**Looker Studio**（前身為 Google Data Studio，2022 年更名）是 Google 提供的免費雲端報表工具，可以把各種數據來源的資料，用拖拉的方式組成視覺化的互動式儀表板（Dashboard）。

```
GA4 探索報表 = 廚房裡做菜（原料處理、實驗配方）
Looker Studio = 精美擺盤後端上桌（給客人看的成品）
```

| 特性 | GA4 探索報表 | Looker Studio |
|------|-------------|---------------|
| 主要使用者 | 數據分析師、行銷操盤手 | 老闆、團隊成員、客戶——所有人 |
| 操作門檻 | 需理解維度、指標、區隔等概念 | 打開連結就能看，不需任何背景知識 |
| 客製程度 | 功能強大但版面固定 | 版面完全自由，像做簡報一樣 |
| 分享方式 | 需要 GA4 帳號與權限 | 一個連結，任何人都能看 |
| 數據更新 | 需手動操作查看 | 自動即時更新，打開就是最新數據 |
| 數據來源 | 只能看 GA4 | 可同時連結 GA4、Google Ads、Search Console 等 |

**三大優勢**：(1) **免費**——不限報表數量，對中小品牌最務實；(2) **即時更新**——打開就是最新數據，不需手動匯出；(3) **一鍵分享**——一個連結，任何人都能看到完整互動式報表。

> 想像你每天早上打開信箱，就有一份自動更新的 MovieTribe 營運快報等著你——流量、來源、熱門頁面一目了然。這就是 Looker Studio 能幫你實現的事。

## 4. 連結 GA4 數據源

### 4.1 資料來源與連接器的概念

Looker Studio 本身不儲存任何資料，它只是一個「展示工具」，需要透過**連接器（Connector）** 連到外部數據。就像投影機本身沒有影片，需要接上筆電才能放映。

| 常見連接器 | 數據來源 | 用途 |
|-----------|---------|------|
| Google Analytics | GA4 | 網站流量、行為、轉換 |
| Google Ads | Google 廣告後台 | 廣告花費、點擊、曝光 |
| Search Console | Google 搜尋 | 搜尋排名、點擊率、曝光次數 |
| Google Sheets | Google 試算表 | 自訂資料、手動輸入數據 |
| BigQuery | Google 大數據倉儲 | 大量原始數據分析 |

> 本週先專注在 GA4 連接器。Week 11 再學習如何同時使用多個數據源。

### 4.2 實作：串接 GA4 數據源

1. 開啟瀏覽器，前往 [Looker Studio](https://lookerstudio.google.com/)
2. 確認使用與 GA4 相同的 Google 帳號登入
3. 點擊左上角「**建立**」→「**報表**」
4. 系統要求新增數據來源——搜尋「Google Analytics」→ 選擇「**Google Analytics（分析）**」
5. 授權 Looker Studio 存取你的 GA4 資料（首次使用才需要）
6. 選擇 GA4 帳戶 → 選擇 MovieTribe GA4 資源 → 點擊「**新增**」

```
Google Analytics 帳戶    GA4 資源              確認
┌───────────────┐    ┌──────────────┐    ┌─────────┐
│ 你的帳戶名稱   │ →  │ MovieTribe   │ →  │  新增    │
│               │    │ GA4 Property │    │         │
└───────────────┘    └──────────────┘    └─────────┘
```

### 4.3 維度與指標的對應

連接成功後，Looker Studio 已「知道」GA4 裡有哪些維度和指標。回顧 Week 2——維度（Dimensions）描述「是什麼」，指標（Metrics）量化「有多少」：

| GA4 中的名稱 | Looker Studio 中的名稱 | 資料類型 | 範例 |
|-------------|----------------------|---------|------|
| 工作階段預設管道群組 | Session default channel group | 維度（文字） | Organic Search、Direct |
| 裝置類別 | Device category | 維度（文字） | mobile、desktop |
| 頁面標題 | Page title | 維度（文字） | MovieTribe - 首頁 |
| 活躍使用者 | Active users | 指標（數字） | 1,250 |
| 工作階段 | Sessions | 指標（數字） | 2,800 |
| 互動率 | Engagement rate | 指標（百分比） | 65.3% |

## 5. 報表架構設計（商業邏輯思維）

在動手拉圖表之前，先想清楚：**這份報表是給誰看的？他想知道什麼？**

```
報表設計三問：
  1. 讀者是誰？         → 老闆、行銷團隊、自己
  2. 他最關心什麼？      → 流量變化？來源分布？轉換成效？
  3. 他需要什麼行動依據？ → 判斷是否要加碼廣告？還是調整內容策略？
```

報表就像菜單——不是把後廚所有食材列上去，而是精選客人最需要的菜。**每張圖表都應該對應一個具體的商業問題。**

根據 MovieTribe 營運需求，建議日報表設計成四頁結構：

| 頁面 | 名稱 | 核心問題 | 主要圖表 |
|:----:|------|---------|---------|
| P1 | 概覽頁 | 「整體狀況如何？」 | KPI 計分卡、每日流量趨勢圖 |
| P2 | 流量來源頁 | 「使用者從哪裡來？」 | 管道分佈長條圖、來源明細表格 |
| P3 | 行為分析頁 | 「使用者在看什麼？」 | 熱門頁面表格、裝置分佈圓餅圖 |
| P4 | 轉換成效頁 | 「關鍵行為達成狀況？」 | 轉換事件計分卡、轉換趨勢圖 |

> 本週先完成 P1 概覽頁。Week 11 會完成其餘三頁，並加入進階互動功能（篩選器、下鑽、日期範圍控制項）。

## 6. 常用圖表類型與適用場景

Looker Studio 提供十幾種圖表，但日常最常用的是以下五種，學會這五種就能搞定 90% 的需求。

| 圖表類型 | 外觀 | 適用場景 | 不適合 |
|---------|------|---------|--------|
| **計分卡**（Scorecard） | 一個大數字 + 變化% | 單一 KPI 現狀，一秒抓重點 | 需要比較多個值 |
| **時間序列圖**（Time Series） | 折線圖，X 軸時間 | 趨勢走向——成長、下降或穩定 | 無時間維度的靜態排名 |
| **長條圖**（Bar Chart） | 長條比較高度 | 不同類別「比大小」 | 超過 15 個類別 |
| **圓餅圖**（Pie Chart） | 扇形佔比 | 各部分佔整體比例（2-5 類） | 超過 5 類或差異不大 |
| **表格**（Table） | 列欄格式 | 精確數字、多指標並列 | 需要一秒傳達趨勢 |

> 先用圖表抓讀者注意力，再附表格讓需要的人查細節。圓餅圖常被「濫用」——超過 5 個類別時，改用長條圖搭配百分比標籤更清楚。

### 圖表選擇速查表

```
你想呈現什麼？
├─ 單一數字的「現在狀態」      → 計分卡
├─ 隨時間的變化趨勢            → 時間序列圖
├─ 不同類別之間「比大小」       → 長條圖
├─ 各部分佔整體的「比例」       → 圓餅圖（≤5 類別）
└─ 多維度的精確數字             → 表格
```

## 7. 實作步驟：從零建立第一份報表

新手 5 步驟上手：**選空白報表 → 串接 GA4 → 拉圖表 → 套主題 → 分享**。

### 7.1 Step 1-2：建立空白報表並串接 GA4

1. 前往 [Looker Studio](https://lookerstudio.google.com/)，點擊「**建立**」→「**報表**」
2. 系統自動彈出數據來源選擇——搜尋「Google Analytics」→ 選擇連接器
3. 選擇帳戶 → 選擇 MovieTribe GA4 資源 → 點擊「**新增**」→「**加入報表**」

連接成功後，你會看到空白畫布，左下角顯示已連結的數據源名稱。

### 7.2 Step 3：建立 KPI 計分卡

1. 上方工具列「**新增圖表**」→ 選擇「**計分卡**」（Scorecard）
2. 在畫布上拖拉出方框
3. 右側面板「**資料**」：指標選擇「**活躍使用者**」
4. 右側面板「**樣式**」：字體調為 36px，開啟「**比較日期範圍**」選「上一個期間」

依同樣步驟建立 4 個計分卡，水平排列在報表頂端：

| 計分卡 | 指標 | 商業意義 |
|--------|------|---------|
| 活躍使用者 | Active users | 有多少人來？ |
| 工作階段 | Sessions | 總共來了幾次？ |
| 互動率 | Engagement rate | 來的人有多投入？ |
| 關鍵事件數 | Key events | 重要行為達成了幾次？ |

```
┌──────────────┬──────────────┬──────────────┬───────────────┐
│ 活躍使用者    │  工作階段     │   互動率      │  關鍵事件數   │
│    1,250     │    2,800     │    65.3%     │      48       │
│  ▲ 12.5%    │  ▲ 8.2%     │  ▼ 2.1%     │  ▲ 15.0%     │
└──────────────┴──────────────┴──────────────┴───────────────┘
```

> 排列順序從「量」到「質」——先看多少人來，再看參與程度，最後看目標達成。

### 7.3 Step 4：加入時間趨勢圖

1. 「**新增圖表**」→ 選擇「**時間序列圖表**」（Time Series Chart）
2. 在計分卡下方拖拉出寬幅區域
3. 右側「**資料**」面板：
   - 維度：「**日期**」（X 軸）
   - 指標：「**活躍使用者**」（Y 軸）
   - 可選：新增「**工作階段**」疊加第二條線
4. 「**樣式**」：線條粗細 2-3px，背景保持白色

### 7.4 Step 5：套用主題與分享

**套用主題：** 上方選單「**主題與版面配置**」（Theme and Layout），選擇預設主題或自訂品牌色彩。

| 設定項目 | 建議設定 |
|---------|---------|
| 報表背景 | #F8F9FA（淺灰）或 #FFFFFF（白色） |
| 主色調 | 品牌色或 #4285F4（Google 藍） |
| 字體 | Roboto 或 Noto Sans TC（中英文兼容） |

**分享報表：** 右上角「**分享**」按鈕，四種方式：

| 分享方式 | 適用情境 |
|---------|---------|
| 邀請特定人 | 團隊內部固定成員 |
| 取得連結 | 快速分享給任何人 |
| 排程寄送 | 每日/每週自動寄送 PDF 到信箱 |
| 嵌入 | 放入公司內部網頁 |

> **排程寄送**是「自動化日報表」的關鍵——設定一次後，Looker Studio 會在指定時間自動把 PDF 快照寄到信箱。

## 8. MovieTribe 日報表設計情境

先定義日報表的 3W：

| 問題 | 回答 |
|------|------|
| **Who**（給誰看？） | MovieTribe 經營者、未來合作夥伴 |
| **What**（看什麼？） | 每日流量、使用者來源、熱門內容、關鍵事件 |
| **Why**（看了幹嘛？） | 判斷經營效果、發現異常、決定內容策略 |

**概覽頁版面配置（本週完成）：**

```
┌────────────────────────────────────────────────────────┐
│  MovieTribe 每日營運報表            日期範圍：最近 28 天  │
├─────────────┬─────────────┬─────────────┬──────────────┤
│ 活躍使用者   │  工作階段    │   互動率     │ 關鍵事件數   │
│   1,250     │   2,800     │   65.3%     │     48       │
├─────────────┴─────────────┴─────────────┴──────────────┤
│          每日活躍使用者趨勢（時間序列圖）                  │
├───────────────────────────┬────────────────────────────┤
│  流量管道分佈（長條圖）     │   裝置類別佔比（圓餅圖）     │
├───────────────────────────┴────────────────────────────┤
│            熱門頁面 Top 10（表格）                       │
└────────────────────────────────────────────────────────┘
```

| 元素 | 圖表類型 | 維度 | 指標 |
|------|---------|------|------|
| KPI 區 | 計分卡 ×4 | — | 活躍使用者、工作階段、互動率、關鍵事件數 |
| 趨勢圖 | 時間序列圖 | 日期 | 活躍使用者 |
| 管道分佈 | 長條圖 | 工作階段預設管道群組 | 工作階段 |
| 裝置佔比 | 圓餅圖 | 裝置類別 | 活躍使用者 |
| 熱門頁面 | 表格 | 頁面標題 | 工作階段、活躍使用者、互動率 |

> 版面邏輯是「從上到下、從大到小」——頂部全局數字，中間趨勢與分佈，底部細節。讀者可依需求決定看到哪裡就停。

**讓報表自動更新**：Looker Studio 不儲存快照，每次開啟時直接向 GA4 即時查詢。設定排程寄送（分享 → 排程寄送電子郵件 → 每天上午 9:00），每天早上信箱就有一份自動更新的營運快報。

## 10. FAQ — 常見問題

**Q1：Looker Studio 是免費的嗎？有使用限制嗎？**

完全免費，不限報表數量與共用人數。唯一限制是大數據量下的查詢配額，對 MovieTribe 這類中小型網站完全不用擔心。

**Q2：Looker Studio 和 GA4 探索報表的數據會不會不一樣？**

可能有微小差異（1-2% 以內）。Looker Studio 透過 API 查詢，大數據量下可能啟用取樣（Sampling），但對中小型網站不影響判讀。

**Q3：可以在同一份報表中使用多個數據源嗎？**

可以。每張圖表可選擇不同數據源，但同一張圖表只能用一個。Week 11 會進一步介紹。

**Q4：報表載入很慢怎麼辦？**

依序排查：(1) 縮短日期範圍；(2) 減少圖表數量（每頁不超過 8-10 個）；(3) 限制表格顯示列數（如 Top 10）；(4) 手動重新整理資料。

**Q5：排程寄送的報表是即時數據還是快照？**

是觸發時間點的快照 PDF。要看互動式報表需點擊 Email 中的「在 Looker Studio 中開啟」連結。

**Q6：搞亂了版面可以復原嗎？**

支援 Ctrl+Z / Cmd+Z 復原，也有「版本紀錄」（檔案 → 版本紀錄）可回溯。建議大幅修改前先複製備份。
